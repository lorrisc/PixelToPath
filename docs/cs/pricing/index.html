Za co neplatíte

Každá cena na této stránce je konečná. Co se na vaší faktuře nikdy neobjeví:

  • Žádné opakované předplatné — online nástroj a desktopová aplikace jsou doživotně zdarma, verze Pro je jednorázová platba a API funguje na předplacené kredity, které nikdy nevyprší.
  • Žádný účet ani kreditní karta do začátku — převádějte v prohlížeči bez registrace a bezplatný plán API vyžaduje pouze e-mailovou adresu.
  • Žádné vodoznaky — SVG, které si stáhnete, je identické, ať už pochází z bezplatné nebo placené verze.
  • Žádné skryté poplatky — DPH se vypočítá automaticky při platbě a nevyužité API kredity jednoduše počkají, dokud je nebudete potřebovat.

Ceník FAQ

Je online převodník opravdu zdarma?

Ano. Online nástroj je neomezený a nevyžaduje žádný účet. Je to stejný engine jako u ostatních verzí — zdarma znamená opravdu zdarma, bez jakýchkoli vodoznaků na výsledku.

Je licence Pro předplatné?

Ne. Pro desktopová aplikace je jednorázová platba 39 € (bez DPH) za doživotní licenci: 1 uživatel, použitelná až na 3 počítačích. Nejsou zde žádné opakované poplatky.

Vyprší někdy platnost API kreditů?

Ne. Zakoupené kredity zůstávají na vašem účtu, dokud je nevyužijete. Každý účet také získává 10 bezplatných konverzí každý měsíc, které se spotřebují před kredity.

Jak probíhají platby?

Všechny platby zpracovává Lemon Squeezy jako oficiální prodejce: kreditní karta, Apple Pay nebo PayPal. DPH nebo daň z prodeje se vypočítá automaticky a faktura vám je zaslána e-mailem.

Mohu na vyšší verzi přejít později?

Kdykoliv. Bezplatné verze nemají časové omezení, a verzi Pro nebo API kredity můžete přidat, jakmile se vaše potřeby zvýší — všechny využívají stejný převodní engine.

Začněte zdarma ještě dnes

Každá verze má bezplatnou možnost. Vyberte si jednu a převeďte svůj první obrázek během několika sekund.
