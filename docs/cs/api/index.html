API PixelToPath

Vektorizujte své obrázky programově pomocí jednoho REST volání. Odešlete soubor PNG, JPG, BMP nebo WebP a získejte čisté SVG, připravené pro produkci. Černobílé kresby jsou vektorizovány pomocí Potrace, barevné obrázky pomocí VTracer — stejné enginy jako bezplatný online převodník.

Rychlý start

Ve třech krocích převedete obrázky do SVG z vašeho terminálu, skriptů nebo aplikace.

1 · Vytvořte si účet

Zaregistrujte se na klientském portálu pomocí e-mailové adresy a hesla (více než 10 znaků). Není nutná kreditní karta.

2 · Vytvořte API klíč

V portálu si vytvořte klíč. Zobrazí se pouze jednou — pečlivě si ho uschovejte. Klíče vypadají jako ptp_live_… a lze je kdykoli odvolat.

3 · Zavolejte /v1/convert

Odešlete svůj obrázek jako multipart/form-data se svým klíčem v hlavičce Authorization. SVG vám bude vráceno v těle odpovědi.

Vaše první konverze

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

Interaktivní reference: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

Ověřování

Každý požadavek je ověřen pomocí Bearer tokenu v hlavičce Authorization:

Authorization: Bearer ptp_live_0123abc…
  • Klíče jsou tajné: jsou uloženy na serveru zahašované a zobrazí se pouze jednou při vytvoření. Ztratili jste klíč? Odvolejte ho a vytvořte si nový.
  • Jeden účet, více klíčů: vytvořte si až 5 aktivních klíčů pro oddělení vašich projektů. Vaše měsíční bezplatná kvóta se počítá na účet, ne na klíč.
  • Okamžité odvolání: odvolaný klíč okamžitě přestane fungovat, ať už z portálu nebo prostřednictvím odpovědi API zablokovaného účtu.

POST /v1/convert

Nahrání a konverze v jednom bezstavovém volání. Úspěšné volání stojí maximálně 1 kredit — neúspěšná volání, neplatná volání nebo volání omezená limitem požadavků nestojí nic.

Požadavek (multipart/form-data)

Pole Typ Výchozí Popis
file file — Obrázek k převodu. PNG, JPEG, BMP nebo WebP · max 20 MB · max 50 Mpx · min 64×64 px.
colormode string color <code>color</code> používá engine VTracer, <code>binary</code> používá Potrace (černobíle).
mode string spline Pouze pro Color (VTracer) — ignorováno v binárním režimu. spline | polygon | none
hierarchical string stacked Pouze pro Color (VTracer) — ignorováno v binárním režimu. stacked | cutout
filter_speckle int 4 Pouze pro Color (VTracer) — ignorováno v binárním režimu. 0–16 — odstraní malé skvrny šumu.
color_precision int 6 Pouze pro Color (VTracer) — ignorováno v binárním režimu. 1–8 — počet platných bitů na barevný kanál.
layer_difference int 16 Pouze pro Color (VTracer) — ignorováno v binárním režimu. 0–64 — vzdálenost mezi barevnými vrstvami.
corner_threshold int 60 0–180 — úhel pro detekci rohů (oba enginy).
length_threshold float 4.0 3.5–10 — minimální délka segmentu (oba enginy).
splice_threshold int 45 0–180 — úhel oříznutí cesty (oba enginy).
path_precision int 3 0–8 — počet desetinných míst v souřadnicích cesty.
invert bool false Pouze pro Binary (Potrace) — ignorováno v barevném režimu. Sledovat světlé oblasti místo tmavých oblastí.
turdsize int 2 Pouze pro Binary (Potrace) — ignorováno v barevném režimu. 0–20 — odstraní malé skvrny až do této velikosti.
alphamax float 1.0 Pouze pro Binary (Potrace) — ignorováno v barevném režimu. 0–1.334 — práh pro vyhlazení rohů.
opttolerance float 0.2 Pouze pro Binary (Potrace) — ignorováno v barevném režimu. 0–10 — tolerance optimalizace křivek.

Dva enginy, vybrané pomocí "colormode"

API spouští přesně stejné enginy jako bezplatný online převodník a desktopová aplikace:

binary — Potrace

Černobílé trasování pro perokresby, skeny, náčrty a loga. Tmavá část obrázku (stupně šedi < 50 %) je převedena na bílé pozadí. Vylaďte výsledek pomocí turdsize (odstranění šumu), alphamax (vyhlazení rohů) a opttolerance (optimalizace cest).

color — VTracer

Vektorizace ve vrstvených barvách pro ilustrace, kreslené filmy a fotografie. Ovládejte úroveň detailů pomocí filter_speckle, color_precision, layer_difference a přizpůsobení křivek pomocí mode (spline, polygon, none).

Obrázky jsou předzpracovány přesně tak, jak na webu: nejdelší strana je před konverzí změněna na 1500 px a API vrací zjištěný typ obrázku (line_art, logo, photo nebo illustration) v hlavičce X-Detected-Type.

Odpověď

Při úspěchu: 200 OK s image/svg+xml — tělem odpovědi je samotný soubor SVG. Informační hlavičky:

Hlavička Popis
X-Credits-RemainingZbývající placené kredity na účtu po odečtení tohoto volání.
X-Free-RemainingZbývající bezplatné konverze tento měsíc.
X-Detected-TypeZjištěný typ obrázku (info): line_art, logo, photo nebo illustration.
X-Processing-TimeČas zpracování na serveru v sekundách.

Příklady kódu

Zkopírujte a upravte. API používá standardní multipart/form-data, takže funguje jakýkoli HTTP klient.

cURL

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "colormode=color" \
  -F "filter_speckle=4" \
  -o photo.svg

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

Často kladené otázky

Co se počítá jako konverze?

Úspěšné volání POST /v1/convert, které vrací SVG. Neúspěšná volání (neplatný obrázek, špatné parametry, dosažený limit požadavků, chyba serveru) a volání GET /v1/me se nikdy neúčtují.

Jak se počítá měsíční bezplatná kvóta?

Na účet, podle kalendářního měsíce UTC — resetuje se 1. dne v měsíci v 00:00 UTC. Vytvořením více API klíčů se bezplatná kvóta nenásobí: všechny klíče pod stejným účtem sdílejí stejných 10 bezplatných konverzí.

Vyprší platnost kreditů?

Ne. Zakoupené kredity zůstávají na vašem účtu, dokud je nevyužijete. Spotřebovávají se pouze po vyčerpání 10 měsíčních bezplatných konverzí.

Jak získám více konverzí v měsíci?

Kupte si předplacené obrázky z klientského portálu — libovolné množství, v balíčcích po 50. Vždy vidíte přesně, kolik obrázků dostanete: 50 obrázků za 2,50 €, 500 obrázků za 20 €, 2 500 obrázků za 75 €, 10 000 obrázků za 200 €, 50 000 obrázků za 500 €. Kredity se na váš účet přidají automaticky během několika sekund po zaplacení — žádný licenční klíč, nic k zadávání.

Co se stane, když ztratím svůj API klíč?

Klíče jsou uloženy zahašované, a proto je nelze obnovit. Odvolejte ztracený klíč v portálu a vytvořte si nový — bude okamžitě aktivní.

Jaké formáty obrázků jsou podporovány?

PNG, JPEG, BMP a WebP, do velikosti 20 MB a rozlišení 50 megapixelů a nejméně 64×64 pixelů. Obrázky, jejichž nejdelší strana přesahuje 1500 px, se před konverzí zmenší, přesně jako na bezplatném webu.
