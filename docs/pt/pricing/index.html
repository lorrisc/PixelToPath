O que você não paga

Todo preço nesta página é o preço total. O que nunca aparecerá na sua fatura:

  • Nada recorrente — a ferramenta online e o aplicativo de desktop são grátis para sempre, a versão Pro é um pagamento único, e a API funciona com créditos pré-pagos que nunca expiram.
  • Sem conta ou cartão de crédito para começar — converta no navegador sem se inscrever, e o plano gratuito da API só pede um e-mail.
  • Sem marcas d'água, nunca — o SVG que você baixa é idêntico se vier de uma versão gratuita ou paga.
  • Sem cobranças surpresa — o IVA é calculado automaticamente no checkout e os créditos de API não utilizados simplesmente aguardam até que você precise deles.

FAQ sobre Preços

O conversor online é realmente grátis?

Sim. A ferramenta online é ilimitada e não requer conta. É o mesmo motor de todas as outras versões — grátis significa grátis, sem marca d'água no resultado.

A licença Pro é uma assinatura?

Não. O App Desktop Pro tem um pagamento único de €39 (exclui IVA) para uma licença vitalícia: 1 usuário, utilizável em até 3 máquinas. Não há cobrança recorrente.

Os créditos da API expiram?

Não. Os créditos comprados permanecem na sua conta até você usá-los. Toda conta também recebe 10 conversões grátis todo mês, consumidas antes dos créditos.

Como os pagamentos são processados?

Todos os pagamentos passam pela Lemon Squeezy como comerciante oficial: cartão, Apple Pay ou PayPal, IVA/imposto de vendas calculado automaticamente e fatura enviada por e-mail.

Posso atualizar depois?

A qualquer momento. As versões gratuitas não têm limite de tempo, e a licença Pro ou os créditos de API podem ser adicionados sempre que suas necessidades aumentarem — todas elas usam o mesmo motor de conversão.
