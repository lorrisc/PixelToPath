지불하지 않아도 되는 것

이 페이지의 모든 가격은 최종 가격입니다. 청구서에 절대 포함되지 않는 항목:

  • 반복되는 비용 없음 — 온라인 도구와 데스크톱 앱은 평생 무료이며, Pro는 일회성 결제이고, API는 만료되지 않는 선불 크레딧으로 운영됩니다.
  • 시작하기 위한 계정이나 신용카드 없음 — 가입 없이 브라우저에서 변환할 수 있으며 API 무료 티어는 이메일만 요구합니다.
  • 워터마크 절대 없음 — 다운로드하는 SVG는 무료 버전에서 오든 유료 버전에서 오든 동일합니다.
  • 예상치 못한 청구 없음 — 결제 시 VAT가 자동으로 계산되며 사용하지 않은 API 크레딧은 필요할 때까지 유지됩니다.

가격 관련 FAQ

온라인 변환기는 정말 무료인가요?

네. 온라인 도구는 무제한이며 계정이 필요하지 않습니다. 다른 모든 버전과 동일한 엔진을 사용합니다. 무료는 정말 무료를 의미하며 결과물에 워터마크가 없습니다.

Pro 라이선스는 구독인가요?

아니요. Desktop App Pro는 평생 라이선스에 대해 39€(VAT 별도)의 일회성 결제입니다: 사용자 1명이 최대 3대의 기기에서 사용할 수 있습니다. 반복 청구가 없습니다.

API 크레딧은 만료되나요?

아니요. 구매한 크레딧은 사용할 때까지 계정에 남아 있습니다. 또한 모든 계정에는 매월 10회의 무료 변환이 제공되며, 이는 크레딧보다 먼저 사용됩니다.

결제는 어떻게 처리되나요?

모든 결제는 공식 리셀러인 Lemon Squeezy를 통해 이루어집니다: 카드, Apple Pay 또는 PayPal 지원, VAT/판매세가 자동으로 계산되며 이메일로 인보이스가 전송됩니다.

나중에 업그레이드할 수 있나요?

언제든지 가능합니다. 무료 버전에는 시간 제한이 없으며, 필요가 커지면 Pro 또는 API 크레딧을 추가할 수 있습니다 — 모두 동일한 변환 엔진을 사용합니다.
