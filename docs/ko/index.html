이미지를 SVG로 변환
무료 & 오픈 소스

PixelToPath는 PNG, JPG, BMP 및 WebP 이미지를 확장 가능한 벡터 그래픽으로 변환합니다. 풀 컬러 지원, 라이브 미리보기 및 워터마크 없음.

API

코드에서 대규모로 벡터화하세요. 하나의 REST 호출로 이미지를 전송하고 깔끔한 SVG를 받으세요.

  • 매월 10회 무료 변환
  • 웹사이트와 동일한 엔진(Potrace + VTracer)
  • 프로덕션 레벨의 SVG 출력
  • 최대 5개의 API 키, 키당 속도 제한
  • 만료되지 않는 크레딧 팩
