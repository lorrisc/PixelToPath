API PixelToPath

Vettorializza immagini programmaticamente con una singola chiamata REST. Carica un file PNG, JPG, BMP o WebP, e ottieni un SVG pulito e pronto per la produzione. I disegni in bianco e nero sono tracciati da Potrace, le immagini a colori da VTracer — gli stessi motori del convertitore online gratuito.

Guida rapida

Tre passaggi e starai convertendo immagini in SVG dal tuo terminale, dai tuoi script o dalla tua app.

1 · Crea il tuo account

Registrati sul portale clienti con la tua email e una password (10+ caratteri). Nessuna carta di credito richiesta.

2 · Crea una chiave API

Nel portale, crea una chiave. Ti verrà mostrata una sola volta — conservala in un luogo sicuro. Le chiavi si presentano come ptp_live_… e possono essere revocate in qualsiasi momento.

3 · Chiama /v1/convert

Invia la tua immagine come multipart/form-data con la tua chiave nell'header Authorization. L'SVG viene restituito nel corpo della risposta.

La tua prima conversione

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

Riferimento interattivo: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

Autenticazione

Ogni richiesta è autenticata con un token Bearer nell'header Authorization:

Authorization: Bearer ptp_live_0123abc…
  • Le chiavi sono segrete: vengono salvate tramite hash lato server e mostrate solo una volta al momento della creazione. Chiave smarrita? Revocala e creane una nuova.
  • Un account, più chiavi: crea fino a 5 chiavi attive per separare i tuoi progetti. La quota mensile gratuita viene conteggiata per account, non per chiave.
  • Revoca immediata: una chiave revocata smette di funzionare immediatamente, sia che venga revocata dal portale sia se l'account viene bannato.

POST /v1/convert

Caricamento e conversione in una singola chiamata senza stato (stateless). Una chiamata andata a buon fine costa al massimo 1 credito — le chiamate fallite, non valide o limitate dal rate limiting non costano nulla.

Richiesta (multipart/form-data)

Campo Tipo Predefinito Descrizione
file file — L'immagine da convertire. PNG, JPEG, BMP o WebP · max 20 MB · max 50 Mpx · min 64×64 px.
colormode string color <code>color</code> usa il motore VTracer, <code>binary</code> usa Potrace (bianco e nero).
mode string spline Solo per Color (VTracer) — ignorato in modalità binary. spline | polygon | none
hierarchical string stacked Solo per Color (VTracer) — ignorato in modalità binary. stacked | cutout
filter_speckle int 4 Solo per Color (VTracer) — ignorato in modalità binary. 0–16 — rimuove piccole macchie di rumore.
color_precision int 6 Solo per Color (VTracer) — ignorato in modalità binary. 1–8 — numero di bit significativi per canale di colore.
layer_difference int 16 Solo per Color (VTracer) — ignorato in modalità binary. 0–64 — distanza tra i livelli di colore.
corner_threshold int 60 0–180 — angolo di rilevamento degli angoli (entrambi i motori).
length_threshold float 4.0 3.5–10 — lunghezza minima del segmento (entrambi i motori).
splice_threshold int 45 0–180 — angolo di giunzione dei percorsi (entrambi i motori).
path_precision int 3 0–8 — cifre decimali nelle coordinate del percorso.
invert bool false Solo per Binary (Potrace) — ignorato in modalità color. Traccia le aree chiare invece di quelle scure.
turdsize int 2 Solo per Binary (Potrace) — ignorato in modalità color. 0–20 — sopprime le imperfezioni fino a questa dimensione.
alphamax float 1.0 Solo per Binary (Potrace) — ignorato in modalità color. 0–1.334 — soglia di smussatura degli angoli.
opttolerance float 0.2 Solo per Binary (Potrace) — ignorato in modalità color. 0–10 — tolleranza per l'ottimizzazione delle curve.

Due motori, scelti tramite "colormode"

L'API esegue esattamente gli stessi motori del convertitore online gratuito e dell'app desktop:

binary — Potrace

Tracciamento in bianco e nero di disegni al tratto, scansioni, schizzi e loghi. La parte scura dell'immagine (scala di grigi < 50%) viene tracciata su sfondo bianco. Affina il risultato con turdsize (rimozione del rumore), alphamax (smussatura degli angoli) e opttolerance (ottimizzazione dei percorsi).

color — VTracer

Vettorializzazione a colori a livelli per illustrazioni, cartoni animati e foto. Controlla il livello di dettaglio con filter_speckle, color_precision, layer_difference e l'adattamento delle curve con mode (spline, polygon, none).

Le immagini vengono pre-elaborate esattamente come sul sito web: il lato più lungo viene ridimensionato a 1500 px prima della conversione, e l'API restituisce il tipo di immagine rilevato (line_art, logo, photo o illustration) nell'header X-Detected-Type.

Risposta

In caso di successo: 200 OK con image/svg+xml — il corpo della risposta è il file SVG stesso. Header informativi:

Header Descrizione
X-Credits-RemainingCrediti a pagamento rimasti sull'account, dopo l'addebito per questa chiamata.
X-Free-RemainingConversioni gratuite rimaste questo mese.
X-Detected-TypeTipo di immagine rilevata (info): line_art, logo, photo o illustration.
X-Processing-TimeTempo di elaborazione del server in secondi.

Limiti di frequenza (Rate limits)

I limiti si applicano per chiave API, non per IP, in modo che un ufficio condiviso o un runner CI non venga mai penalizzato per il traffico di qualcun altro.

Esempi di codice

Copia, incolla e adatta. L'API usa un semplice multipart/form-data, quindi funziona con qualsiasi client HTTP.

cURL

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "colormode=color" \
  -F "filter_speckle=4" \
  -o photo.svg

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

Domande frequenti

Cosa conta come una conversione?

Una chiamata POST /v1/convert andata a buon fine che restituisce un SVG. Le chiamate fallite (immagine non valida, parametri errati, rate limit raggiunto, errore del server) e le chiamate GET /v1/me non vengono mai addebitate.

Come viene conteggiata la quota gratuita mensile?

Per account, in base al mese solare UTC — si azzera il 1° di ogni mese alle 00:00 UTC. Creare diverse chiavi API non moltiplica la quota gratuita: tutte le chiavi di un account condividono le stesse 10 conversioni gratuite.

I crediti scadono?

No. I crediti acquistati rimangono sul tuo account finché non li usi. Vengono consumati solo dopo che le tue 10 conversioni gratuite mensili sono esaurite.

Come posso ottenere più conversioni in un mese?

Acquista immagini prepagate dal portale clienti — in qualsiasi quantità, in lotti di 50. Vedi sempre esattamente quante immagini ottieni: 50 immagini €2.50, 500 immagini €20, 2.500 €75, 10.000 €200, 50.000 €500. I crediti vengono aggiunti al tuo account automaticamente entro pochi secondi dal pagamento — nessuna chiave di licenza, niente da inserire.

Cosa succede se perdo la mia chiave API?

Le chiavi vengono salvate tramite hash, quindi non possono essere recuperate. Revoca la chiave smarrita nel portale e creane una nuova — ha effetto immediato.

Quali formati di immagine sono supportati?

PNG, JPEG, BMP e WebP, fino a 20 MB e 50 megapixel, con almeno 64×64 pixel. Le immagini più grandi di 1500 px sul loro lato più lungo vengono ridimensionate prima della conversione, esattamente come sul sito web gratuito.
