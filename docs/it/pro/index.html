Tutto ciò che c'è nell'App Gratuita - Con Automazione

Monitoraggio tramite Hot Folder

Trasforma qualsiasi cartella in una pipeline di conversione automatizzata. Non appena appare una nuova immagine, PixelToPath Pro la rileva e la converte istantaneamente in SVG - nessun clic, nessuna attesa, nessuna supervisione.

  • Trascina un file e ottieni un SVG pronto all'uso
  • I nuovi file vengono rilevati e convertiti in pochi secondi
  • I file originali rimangono intatti; gli SVG vengono salvati nella cartella di output
  • Ideale per unità condivise, cartelle di esportazione e pipeline di asset

Conversione in Batch

Smetti di convertire le immagini una per una. Importa tutta la tua libreria - 10, 100 o più file PNG, JPG, BMP o WebP - e convertile tutte in SVG in una sola volta.

  • Metti in coda centinaia di immagini contemporaneamente
  • Un unico profilo di impostazioni applicato a ogni file
  • Converti un intero set di icone con un solo clic
  • Avanzamento e risultati in una vista chiara

Interfaccia a Riga di Comando (CLI)

Gestisci le conversioni dal tuo terminale. La CLI ti offre tutta la potenza del motore VTracer in un unico comando, così la vettorializzazione diventa semplicemente un altro passaggio nei tuoi script.

  • Converti con un solo comando, non è necessaria alcuna interfaccia
  • Integra l'esportazione SVG in script di build e pipeline CI
  • Pianifica lavori ricorrenti con cron o Utilità di pianificazione
  • Stesse impostazioni e qualità di output dell'app desktop

Come funziona l'Hot Folder

Impostalo una volta e dimenticalo: ogni file che aggiungi viene convertito da solo.

  1. Scegli le tue cartelle: seleziona la cartella da monitorare e dove devono andare gli SVG.
  2. Aggiungi un'immagine: salva o copia qualsiasi file PNG, JPG, BMP o WebP nella cartella monitorata.
  3. Conversione istantanea: PixelToPath Pro rileva il nuovo file e lo converte automaticamente.
  4. Ritira il tuo SVG: il file vettoriale finito e pronto all'uso ti aspetta nella cartella di output.

Domande Frequenti

Ho bisogno di PixelToPath Pro per convertire le immagini?

No. L'app desktop gratuita converte già i file PNG, JPG, BMP e WebP in SVG, offline e senza limiti. PixelToPath Pro aggiunge l'automazione: monitoraggio tramite hot folder, conversione in batch di centinaia di immagini contemporaneamente e un'interfaccia a riga di comando.

Cos'è esattamente un hot folder?

Un hot folder è una cartella che PixelToPath Pro continua a monitorare. Ogni volta che vi appare una nuova immagine (perché l'hai salvata, copiata o trascinata lì), l'app la rileva e la converte automaticamente in SVG, per poi posizionare il risultato nella cartella di output da te scelta. Non devi mai aprire l'app o cliccare su converti.

Quante immagini posso convertire contemporaneamente con la modalità batch?

Puoi mettere in coda tutta la tua libreria (importare 100 immagini o diverse centinaia) e convertirle tutte in una sola volta. L'unico limite è il tuo dispositivo, poiché ogni conversione viene eseguita localmente sulla tua CPU con il motore VTracer.

Cosa posso fare con la CLI?

L'interfaccia a riga di comando ti consente di convertire le immagini con un singolo comando, senza aprire l'interfaccia grafica. Puoi integrare la vettorializzazione in script shell, pipeline di build e processi CI, oppure pianificare conversioni ricorrenti con strumenti come cron o Utilità di pianificazione di Windows.

La versione gratuita rimarrà gratuita?

Sì. L'app desktop gratuita rimane gratuita, illimitata e open source con licenza MIT. PixelToPath Pro è un aggiornamento opzionale per i flussi di lavoro professionali; l'app gratuita non è limitata nelle funzioni o nel tempo in alcun modo.

Quali sistemi operativi supporta PixelToPath Pro?

PixelToPath Pro funziona su Windows (64 bit) e Linux, le stesse piattaforme dell'app desktop gratuita. Tutto funziona completamente offline, esattamente come la versione gratuita.

Il prezzo di 39 € include le tasse?

No, 39 € è il prezzo esclusa l'IVA. A seconda del tuo paese e di dove completi l'acquisto, l'IVA o l'imposta sulle vendite potrebbero essere aggiunte al momento del pagamento.

Su quanti dispositivi posso installare PixelToPath Pro?

La licenza Pro è un acquisto una tantum: 39 € IVA escl., tua per tutta la vita. Copre un singolo utente e può essere attivata su un massimo di 3 dispositivi (ad esempio una workstation desktop, un laptop e un computer in studio).
