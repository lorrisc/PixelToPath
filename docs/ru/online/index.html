PNG против SVG — с реальным результатом инструмента

Ниже — реальная конвертация, выполненная конвертером на этой странице. Этот крошечный логотип 128 px под увеличением: PNG распадается на квадратные пиксели, а векторизованный SVG остаётся идеально чётким.

PNG хранит изображение в виде фиксированной сетки пикселей, поэтому оно выглядит правильно только в том размере, для которого было экспортировано: увеличьте логотип — края расплываются, а для экранов с высокой плотностью пикселей приходится поставлять две-три более тяжёлые версии одного и того же файла. SVG описывает те же фигуры кривыми и координатами, поэтому браузер перерисовывает их чёткими в любом размере из одного небольшого файла. Сравнение выше показывает результат на реальном логотипе. На практике: конвертируйте логотипы, иконки, линейные рисунки и плоские иллюстрации в SVG, а фотографии, скриншоты и текстуры оставляйте в PNG, WebP или JPG — там пиксельные форматы действительно сжимаются лучше.

PNG против SVG: наглядное сравнение

Та же разница, сведённая в таблицу:

Критерий PNG (растр) SVG (вектор)
Масштабирование Размывается, как только изображение увеличивают Чёткий в любом размере, от 16px до 4K
Размер файла (логотип) От 40 до 80 КБ, а при @2x — вдвое больше От 2 до 12 КБ, один файл для всех экранов
Экраны с высокой плотностью пикселей Требуются отдельные версии @1x, @2x и @3x Один неизменный файл
Редактирование Пиксели сведены в один слой: любое изменение требует исходного файла Каждая фигура — редактируемый контур
Лучше всего для Фото, скриншоты, сложные изображения Логотипы, иконки, плоские иллюстрации

Один файл, три пресета

Все три SVG — реальные конвертации этого PNG 512 px пресетами этого конвертера. На любом экране — фавикон 16 px или дисплей 4K — тот же файл остаётся чётким.

Бесплатный Векторизатор Изображений

PixelToPath — бесплатный онлайн-векторизатор изображений: он конвертирует любой файл PNG, JPG, BMP или WebP в чистый масштабируемый SVG. Сама технология называется растрово-векторной конвертацией или трассировкой изображения: вместо хранения одного значения цвета на каждый пиксель движок заново собирает ваше изображение из математических кривых, которые браузер идеально перерисовывает в любом размере — от фавикона 16px до дисплея 4K. Растровый файл расплывается при каждом увеличении; векторный — никогда. Загрузите изображение, наблюдайте, как предпросмотр обновляется вживую, пока вы настраиваете параметры, а затем скачайте SVG, готовый для Illustrator, Inkscape и Figma, для вставки на сайт или для лазерного резака и винилового плоттера — без водяных знаков и без регистрации.

Доступны два режима трассировки: полноцветный для иллюстраций и фотографий и черно-белый для логотипов и иконок — при этом каждый параметр можно настроить для более чистого результата.

Какой пресет выбрать?

PixelToPath предлагает три пресета. Вы также можете настроить каждый параметр вручную.

Ч/Б Черно-белое

Преобразует в градации серого. Идеально для одноцветных контуров. Подходит для:

  • Логотипов
  • Иконок и пиктограмм
  • Скетчей
  • Лазерной гравировки

Постер Плоский цвет

Трассировка с наложением слоев с высокой точностью. Подходит для:

  • Иллюстраций
  • Инфографики
  • Стикеров
  • Цифровых артов

Фото Фотографии

Более широкая группировка цветов для обработки сложных реальных фото. Подходит для:

  • Портретов
  • Пейзажей
  • Фото товаров
  • Сложных изображений с градиентами

Частые вопросы

Это действительно бесплатно и без ограничений?

Да, полностью бесплатно. PixelToPath - это Open Source проект (MIT).

Поддерживаются ли цветные изображения?

Да. Мы используем VTracer. Выберите Постер или Фото для цвета.

Сохраняются ли мои файлы?

Нет. Файлы удаляются сразу после обработки.

Какие форматы поддерживаются?

PNG, JPG, JPEG, BMP и WebP. Можно вставить из буфера обмена (Ctrl+V).

Какой максимальный размер файла?

В онлайне - до 20 МБ. Для больших файлов скачайте десктопное приложение.

Почему Ч/Б результат выглядит неправильно?

Включите переключатель Инвертировать в дополнительных настройках.

В чем разница между режимами Сплайн, Полигон и Пиксель?

Сплайн для плавных кривых. Полигон для прямых линий. Пиксель без сглаживания (для пиксель-арта).

Можно использовать SVG в коммерческих целях?

Да, без каких-либо лицензионных ограничений.
