За что вы не платите

Каждая цена на этой странице — полная. То, что никогда не появится в вашем счете:

  • Никаких регулярных платежей — онлайн-инструмент и десктопное приложение бесплатны навсегда, Pro оплачивается один раз, а API работает на предоплаченных кредитах, которые никогда не сгорают.
  • Не требуется аккаунт или кредитная карта для начала — конвертируйте в браузере без регистрации, а для бесплатного тарифа API нужен только адрес электронной почты.
  • Никаких водяных знаков, никогда — скачанный вами SVG идентичен вне зависимости от того, из бесплатной или платной версии он получен.
  • Никаких сюрпризов при оплате — НДС рассчитывается автоматически при оформлении заказа, а неиспользованные кредиты API просто ждут, пока они вам не понадобятся.

Вопросы о ценах

Действительно ли онлайн-конвертер бесплатен?

Да. Онлайн-инструмент не ограничен и не требует аккаунта. Это тот же самый движок, что и во всех остальных версиях — бесплатно означает бесплатно, без водяных знаков на результате.

Является ли лицензия Pro подпиской?

Нет. Десктопное приложение Pro — это единоразовый платеж в размере €39 (без НДС) за пожизненную лицензию: 1 пользователь, возможность использования на 3 машинах. Никаких регулярных платежей нет.

Сгорают ли кредиты API?

Нет. Купленные кредиты остаются на вашем аккаунте, пока вы их не используете. Каждый аккаунт также получает 10 бесплатных конвертаций каждый месяц, которые расходуются до кредитов.

Как обрабатываются платежи?

Все платежи проходят через Lemon Squeezy как официального продавца: карта, Apple Pay или PayPal, НДС/налог с продаж рассчитывается автоматически, а счет отправляется по электронной почте.

Могу ли я перейти на платную версию позже?

В любое время. У бесплатных версий нет ограничений по времени, а Pro или кредиты API можно добавить, когда ваши потребности возрастут — все они используют один и тот же движок конвертации.
