API PixelToPath

Векторизуйте изображения программно с помощью одного REST-запроса. Загрузите файл PNG, JPG, BMP или WebP и получите обратно чистый, готовый к использованию SVG. Черно-белая графика трассируется с помощью Potrace, цветные изображения — с помощью VTracer — тех же движков, что и в бесплатном онлайн-конвертере.

Быстрый старт

Три шага — и вы конвертируете изображения в SVG из терминала, скриптов или вашего приложения.

1 · Создайте аккаунт

Зарегистрируйтесь на клиентском портале с помощью электронной почты и пароля (от 10 символов). Кредитная карта не требуется.

2 · Создайте ключ API

Создайте ключ на портале. Он отображается только один раз — сохраните его в надежном месте. Ключи выглядят как ptp_live_… и могут быть отозваны в любое время.

3 · Вызовите /v1/convert

Отправьте ваше изображение в формате multipart/form-data с вашим ключом в заголовке Authorization. SVG возвращается в теле ответа.

Ваша первая конвертация

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

Интерактивная документация: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

Аутентификация

Каждый запрос аутентифицируется с помощью Bearer-токена в заголовке Authorization:

Authorization: Bearer ptp_live_0123abc…
  • Ключи — это секреты: они хранятся в хешированном виде на стороне сервера и отображаются только один раз при создании. Потеряли ключ? Отзовите его и создайте новый.
  • Один аккаунт, несколько ключей: создайте до 5 активных ключей для разделения ваших проектов. Бесплатная месячная квота рассчитывается на аккаунт, а не на ключ.
  • Мгновенный отзыв: отозванный ключ перестает работать немедленно, будь то через отзыв на портале или через API-ответ для заблокированного аккаунта.

POST /v1/convert

Загрузка и конвертация за один stateless-вызов. Один успешный вызов стоит не более 1 кредита — неудачные, недействительные или ограниченные по скорости вызовы ничего не стоят.

Запрос (multipart/form-data)

Поле Тип По умолчанию Описание
file file — Изображение для конвертации. PNG, JPEG, BMP или WebP · макс. 20 МБ · макс. 50 Мп · мин. 64×64 пкс.
colormode string color <code>color</code> использует движок VTracer, <code>binary</code> использует Potrace (черно-белый).
mode string spline Только для Color (VTracer) — игнорируется в бинарном режиме. spline | polygon | none
hierarchical string stacked Только для Color (VTracer) — игнорируется в бинарном режиме. stacked | cutout
filter_speckle int 4 Только для Color (VTracer) — игнорируется в бинарном режиме. 0–16 — удаляет мелкие пятна шума.
color_precision int 6 Только для Color (VTracer) — игнорируется в бинарном режиме. 1–8 — число значащих бит на цветовой канал.
layer_difference int 16 Только для Color (VTracer) — игнорируется в бинарном режиме. 0–64 — расстояние между цветовыми слоями.
corner_threshold int 60 0–180 — угол обнаружения углов (оба движка).
length_threshold float 4.0 3.5–10 — минимальная длина сегмента (оба движка).
splice_threshold int 45 0–180 — угол разбиения путей (оба движка).
path_precision int 3 0–8 — десятичные знаки в координатах путей.
invert bool false Только для Binary (Potrace) — игнорируется в цветном режиме. Трассировать светлые участки вместо темных.
turdsize int 2 Только для Binary (Potrace) — игнорируется в цветном режиме. 0–20 — подавляет пятна до этого размера.
alphamax float 1.0 Только для Binary (Potrace) — игнорируется в цветном режиме. 0–1.334 — порог сглаживания углов.
opttolerance float 0.2 Только для Binary (Potrace) — игнорируется в цветном режиме. 0–10 — допуск оптимизации кривых.

Два движка, выбираемые с помощью "colormode"

API использует те же движки, что и бесплатный онлайн-конвертер и десктопное приложение:

binary — Potrace

Черно-белая трассировка графики, сканов, набросков и логотипов. Темная часть изображения (градации серого < 50%) трассируется на белом фоне. Тонкая настройка результата с помощью turdsize (удаление шума), alphamax (сглаживание углов) и opttolerance (оптимизация контуров).

color — VTracer

Многослойная цветная векторизация для иллюстраций, мультфильмов и фотографий. Управляйте уровнем детализации с помощью filter_speckle, color_precision, layer_difference и аппроксимацией кривых с помощью mode (spline, polygon, none).

Изображения предварительно обрабатываются точно так же, как на сайте: длинная сторона масштабируется до 1500 пкс перед конвертацией, и API возвращает определенный тип изображения (line_art, logo, photo или illustration) в заголовке X-Detected-Type.

Ответ

В случае успеха: 200 OK с image/svg+xml — тело ответа является самим файлом SVG. Информативные заголовки:

Заголовок Описание
X-Credits-RemainingПлатные кредиты, оставшиеся на аккаунте после списания за этот вызов.
X-Free-RemainingБесплатные конвертации, оставшиеся в этом месяце.
X-Detected-TypeОпределенный тип изображения (инфо): line_art, logo, photo или illustration.
X-Processing-TimeВремя обработки сервером в секундах.

Примеры кода

Скопируйте и адаптируйте. API работает с обычным multipart/form-data, поэтому подойдет любой HTTP-клиент.

cURL

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "colormode=color" \
  -F "filter_speckle=4" \
  -o photo.svg

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

JavaScript

const form = new FormData();

Часто задаваемые вопросы

Что считается одной конвертацией?

Один успешный вызов POST /v1/convert, который возвращает SVG. Неудачные вызовы (недействительное изображение, неправильные параметры, ограничение по скорости, ошибка сервера) и вызовы GET /v1/me никогда не тарифицируются.

Как рассчитывается бесплатная месячная квота?

На аккаунт, по календарному месяцу UTC — она сбрасывается 1-го числа в 00:00 UTC. Создание нескольких ключей API не умножает бесплатную квоту: все ключи аккаунта используют одни и те же 10 бесплатных конвертаций.

Сгорают ли кредиты?

Нет. Купленные кредиты остаются на вашем аккаунте, пока вы их не используете. Они расходуются только после того, как ваши 10 бесплатных конвертаций в месяц будут исчерпаны.

Как мне получить больше конвертаций в месяц?

Покупайте предоплаченные изображения на клиентском портале — в любом количестве, партиями по 50. Вы всегда точно видите, сколько изображений получаете: 50 изображений за €2.50, 500 изображений за €20, 2 500 за €75, 10 000 за €200, 50 000 за €500. Кредиты добавляются на ваш аккаунт автоматически в течение нескольких секунд после оплаты — без лицензионного ключа, ничего вводить не нужно.

Что произойдет, если я потеряю свой ключ API?

Ключи хранятся в хешированном виде, поэтому их нельзя восстановить. Отзовите потерянный ключ на портале и создайте новый — он начнет действовать немедленно.

Какие форматы изображений поддерживаются?

PNG, JPEG, BMP и WebP, размером до 20 МБ и 50 мегапикселей, не менее 64×64 пикселей. Изображения больше 1500 пкс по длинной стороне масштабируются перед конвертацией, точно так же, как на бесплатном сайте.
