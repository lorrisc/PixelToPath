PixelToPath API

Vektorisieren Sie Bilder programmgesteuert mit einem einzigen REST-Aufruf. Laden Sie eine PNG-, JPG-, BMP- oder WebP-Datei hoch und erhalten Sie ein sauberes, produktionsbereites SVG zurück. Schwarz-Weiß-Strichzeichnungen werden von Potrace nachgezeichnet, Farbbilder von VTracer — denselben Engines wie beim kostenlosen Online-Konverter.

Schnellstart

Drei Schritte, und Sie können Bilder über Ihr Terminal, Ihre Skripte oder Ihre App in SVGs umwandeln.

1 · Konto erstellen

Registrieren Sie sich im Kundenportal mit Ihrer E-Mail-Adresse und einem Passwort (10+ Zeichen). Keine Kreditkarte erforderlich.

2 · API-Schlüssel erstellen

Erstellen Sie im Portal einen Schlüssel. Er wird nur einmal angezeigt — bewahren Sie ihn sicher auf. Schlüssel sehen so aus: ptp_live_… und können jederzeit widerrufen werden.

3 · /v1/convert aufrufen

Senden Sie Ihr Bild als multipart/form-data mit Ihrem Schlüssel im Authorization-Header. Das SVG wird im Antwort-Body zurückgegeben.

Ihre erste Konvertierung

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

Interaktive Referenz: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

Authentifizierung

Jede Anfrage wird mit einem Bearer-Token im Authorization-Header authentifiziert:

Authorization: Bearer ptp_live_0123abc…
  • Schlüssel sind geheim: Sie werden serverseitig gehasht gespeichert und nur einmal bei der Erstellung angezeigt. Schlüssel verloren? Widerrufen Sie ihn und erstellen Sie einen neuen.
  • Ein Konto, mehrere Schlüssel: Erstellen Sie bis zu 5 aktive Schlüssel, um Ihre Projekte zu trennen. Ihr monatliches Freikontingent wird pro Konto abgerechnet, nicht pro Schlüssel.
  • Sofortiger Widerruf: Ein widerrufener Schlüssel funktioniert sofort nicht mehr, weder vom Portal aus noch bei API-Anfragen eines gesperrten Kontos.

POST /v1/convert

Upload + Konvertierung in einem einzigen zustandslosen Aufruf. Ein erfolgreicher Aufruf kostet maximal 1 Credit — fehlgeschlagene, ungültige oder durch das Ratenlimit blockierte Aufrufe kosten nichts.

Anfrage (multipart/form-data)

Feld Typ Standard Beschreibung
file file — Das zu konvertierende Bild. PNG, JPEG, BMP oder WebP · max. 20 MB · max. 50 Mpx · min. 64×64 px.
colormode string color <code>color</code> nutzt die VTracer-Engine, <code>binary</code> nutzt Potrace (Schwarz-Weiß).
mode string spline Nur für Farbe (VTracer) — wird im Binary-Modus ignoriert. spline | polygon | none
hierarchical string stacked Nur für Farbe (VTracer) — wird im Binary-Modus ignoriert. stacked | cutout
filter_speckle int 4 Nur für Farbe (VTracer) — wird im Binary-Modus ignoriert. 0–16 — entfernt kleine Rauschflecken.
color_precision int 6 Nur für Farbe (VTracer) — wird im Binary-Modus ignoriert. 1–8 — Anzahl der signifikanten Bits pro Farbkanal.
layer_difference int 16 Nur für Farbe (VTracer) — wird im Binary-Modus ignoriert. 0–64 — Abstand zwischen Farbschichten.
corner_threshold int 60 0–180 — Winkel der Eckerkennung (beide Engines).
length_threshold float 4.0 3.5–10 — minimale Segmentlänge (beide Engines).
splice_threshold int 45 0–180 — Winkel zum Splitten von Pfaden (beide Engines).
path_precision int 3 0–8 — Dezimalstellen in Pfadkoordinaten.
invert bool false Nur für Binary (Potrace) — wird im Farbmodus ignoriert. Zeichnet die hellen statt der dunklen Bereiche nach.
turdsize int 2 Nur für Binary (Potrace) — wird im Farbmodus ignoriert. 0–20 — unterdrückt Flecken bis zu dieser Größe.
alphamax float 1.0 Nur für Binary (Potrace) — wird im Farbmodus ignoriert. 0–1.334 — Schwellenwert für Ecken-Glättung.
opttolerance float 0.2 Nur für Binary (Potrace) — wird im Farbmodus ignoriert. 0–10 — Toleranz der Kurvenoptimierung.

Zwei Engines, gesteuert über "colormode"

Die API führt exakt dieselben Engines aus wie der kostenlose Online-Konverter und die Desktop-App:

binary — Potrace

Schwarz-Weiß-Nachzeichnung von Strichzeichnungen, Scans, Skizzen und Logos. Der dunkle Teil des Bildes (Graustufen < 50%) wird auf weißem Hintergrund nachgezeichnet. Passen Sie die Ausgabe mit turdsize (Rauschentfernung), alphamax (Eckenglättung) und opttolerance (Pfadoptimierung) an.

color — VTracer

Ebenenbasierte Farbvektorisierung für Illustrationen, Cartoons und Fotos. Steuern Sie den Detailgrad mit filter_speckle, color_precision, layer_difference und die Kurvenanpassung mit mode (spline, polygon, none).

Bilder werden genau wie auf der Website vorverarbeitet: Die längste Seite wird vor der Konvertierung auf 1500 px skaliert, und die API gibt den erkannten Bildtyp (line_art, logo, photo oder illustration) im Header X-Detected-Type zurück.

Antwort

Bei Erfolg: 200 OK mit image/svg+xml — der Body ist die SVG-Datei selbst. Informative Header:

X-Free-RemainingVerbleibende kostenlose Konvertierungen in diesem Monat.
X-Detected-TypeErkannter Bildtyp (Info): line_art, logo, photo oder illustration.
X-Processing-TimeVerarbeitungszeit des Servers in Sekunden.

Ratenlimits

Limits gelten pro API-Schlüssel, nicht pro IP. So wird ein gemeinsames Büro oder ein CI-Runner nie für den Datenverkehr anderer bestraft.

Limit Wert
Anfragen pro Minute, pro Schlüssel60
Anfragen pro Tag, pro Schlüssel2 000
Gleichzeitige Konvertierungen, pro Schlüssel2 (weitere Aufrufe warten, dann 429)
Max. Dateigröße / Auflösung20 MB / 50 Mpx

Code-Beispiele

Kopieren, einfügen und anpassen. Die API spricht reines multipart/form-data, sodass jeder HTTP-Client funktioniert.

cURL

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "colormode=color" \
  -F "filter_speckle=4" \
  -o photo.svg

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

Häufig gestellte Fragen

Was zählt als eine Konvertierung?

Ein erfolgreicher POST /v1/convert-Aufruf, der ein SVG zurückgibt. Fehlgeschlagene Aufrufe (ungültiges Bild, falsche Parameter, Ratenlimit überschritten, Serverfehler) und GET /v1/me-Aufrufe werden nie berechnet.

Wie wird das monatliche Freikontingent abgerechnet?

Pro Konto, bezogen auf den UTC-Kalendermonat — es wird am Ersten des Monats um 00:00 Uhr UTC zurückgesetzt. Das Erstellen mehrerer API-Schlüssel multipliziert das Freikontingent nicht: Alle Schlüssel eines Kontos teilen sich dieselben 10 kostenlosen Konvertierungen.

Verfallen Credits?

Nein. Gekaufte Credits bleiben auf Ihrem Konto, bis Sie diese aufbrauchen. Sie werden erst verwendet, nachdem Ihre 10 kostenlosen monatlichen Konvertierungen aufgebraucht sind.

Wie erhalte ich mehr Konvertierungen in einem Monat?

Kaufen Sie Prepaid-Bilder über das Kundenportal — in beliebiger Menge, in 50er-Schritten. Sie sehen immer genau, wie viele Bilder Sie bekommen: 50 Bilder 2,50 €, 500 Bilder 20 €, 2.500 Bilder 75 €, 10.000 Bilder 200 €, 50.000 Bilder 500 €. Credits werden Ihrem Konto innerhalb von Sekunden nach der Zahlung automatisch gutgeschrieben — kein Lizenzschlüssel, keine Eingabe erforderlich.

Was passiert, wenn ich meinen API-Schlüssel verliere?

Schlüssel werden gehasht gespeichert und können daher nicht wiederhergestellt werden. Widerrufen Sie den verlorenen Schlüssel im Portal und erstellen Sie einen neuen — er wird sofort wirksam.

Welche Bildformate werden unterstützt?

PNG, JPEG, BMP und WebP, bis zu 20 MB und 50 Megapixel, mindestens 64×64 Pixel. Bilder, deren längste Seite größer als 1500 px ist, werden vor der Konvertierung verkleinert, genau wie auf der kostenlosen Website.
