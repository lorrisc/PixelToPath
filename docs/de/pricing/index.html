Wofür Sie nicht bezahlen

Jeder Preis auf dieser Seite ist der Endpreis. Was niemals auf Ihrer Rechnung erscheint:

  • Keine wiederkehrenden Kosten — das Online-Tool und die Desktop-App sind für immer kostenlos, Pro ist eine Einmalzahlung, und die API läuft über Prepaid-Credits, die nie verfallen.
  • Kein Konto oder Kreditkarte für den Start — konvertieren Sie im Browser ohne Anmeldung, und der kostenlose API-Tarif erfordert nur eine E-Mail.
  • Niemals Wasserzeichen — das heruntergeladene SVG ist identisch, egal ob es aus einer kostenlosen oder einer kostenpflichtigen Version stammt.
  • Keine versteckten Gebühren — die MwSt. wird beim Checkout automatisch berechnet, und ungenutzte API-Credits warten einfach, bis Sie sie brauchen.

Häufig gestellte Fragen (Preise)

Ist der Online-Konverter wirklich kostenlos?

Ja. Das Online-Tool ist unbegrenzt und erfordert kein Konto. Es nutzt dieselbe Engine wie jede andere Version — kostenlos bedeutet kostenlos, ohne Wasserzeichen in der Ausgabe.

Ist die Pro-Lizenz ein Abonnement?

Nein. Die Desktop-App Pro ist eine Einmalzahlung von 39 € (zzgl. MwSt.) für eine lebenslange Lizenz: 1 Nutzer, verwendbar auf bis zu 3 Geräten. Es gibt keine wiederkehrenden Gebühren.

Verfallen API-Credits?

Nein. Gekaufte Credits bleiben auf Ihrem Konto, bis Sie diese aufbrauchen. Zudem erhält jedes Konto jeden Monat 10 kostenlose Konvertierungen, die vor den Credits verbraucht werden.

Wie werden Zahlungen abgewickelt?

Alle Zahlungen erfolgen über Lemon Squeezy als Merchant of Record: per Karte, Apple Pay oder PayPal. Die Umsatzsteuer/Mehrwertsteuer wird automatisch berechnet, und Sie erhalten eine Rechnung per E-Mail.

Kann ich später ein Upgrade durchführen?

Jederzeit. Die kostenlosen Versionen haben kein Zeitlimit, und Pro- oder API-Credits können hinzugefügt werden, wenn Ihr Bedarf wächst — sie nutzen alle dieselbe Konvertierungs-Engine.
