Apa yang tidak Anda bayar

Setiap harga pada halaman ini adalah harga keseluruhan. Hal-hal yang tidak akan pernah ada di tagihan Anda:

  • Tidak ada biaya berulang — alat online dan aplikasi desktop gratis selamanya, Pro adalah pembayaran satu kali, dan API berjalan dengan kredit prabayar yang tidak pernah kedaluwarsa.
  • Tanpa akun atau kartu kredit untuk memulai — konversi di browser tanpa mendaftar, dan paket gratis API hanya meminta email.
  • Tidak ada tanda air, selamanya — SVG yang Anda unduh identik, baik dari versi gratis maupun berbayar.
  • Tidak ada biaya kejutan — PPN dihitung secara otomatis saat pembayaran, dan kredit API yang belum digunakan hanya akan menunggu sampai Anda membutuhkannya.

Pertanyaan Umum Harga

Apakah konverter online benar-benar gratis?

Ya. Alat online tidak terbatas dan tidak memerlukan akun. Alat ini menggunakan mesin yang sama dengan semua versi lainnya — gratis berarti gratis, tanpa tanda air pada output.

Apakah lisensi Pro merupakan langganan?

Tidak. Aplikasi Desktop Pro adalah pembayaran satu kali sebesar €39 (belum termasuk PPN) untuk lisensi seumur hidup: 1 pengguna, dapat digunakan hingga 3 mesin. Tidak ada biaya berulang.

Apakah kredit API kedaluwarsa?

Tidak. Kredit yang dibeli tetap berada di akun Anda hingga Anda menggunakannya. Setiap akun juga mendapat 10 konversi gratis setiap bulan, yang digunakan sebelum kredit Anda.

Bagaimana pembayaran ditangani?

Semua pembayaran menggunakan Lemon Squeezy sebagai pencatat dagang (merchant of record): kartu, Apple Pay, atau PayPal, PPN/pajak penjualan dihitung secara otomatis, dan faktur dikirimkan melalui email.

Bisakah saya meningkatkan versi di lain waktu?

Kapan saja. Versi gratis tidak memiliki batasan waktu, dan lisensi Pro atau kredit API dapat ditambahkan saat kebutuhan Anda meningkat — semuanya menggunakan mesin konversi yang sama.

Mulai gratis hari ini

Setiap versi dimulai secara gratis. Pilih salah satu dan konversi gambar pertama Anda dalam hitungan detik.
