Semua Fitur di Aplikasi Gratis - Ditambah Otomatisasi

PixelToPath Pro mempertahankan mesin VTracer dan privasi yang sama: semuanya berjalan secara lokal di perangkat Anda. Yang berubah adalah seberapa banyak proses yang tidak perlu lagi Anda lakukan secara manual.

Pemantauan Hot Folder

Ubah folder apa pun menjadi alur konversi otomatis. Begitu gambar baru muncul, PixelToPath Pro mendeteksinya dan langsung mengonversinya ke SVG - tanpa klik, tanpa menunggu, tanpa perlu diawasi.

  • Masukkan file, dapatkan SVG yang siap digunakan
  • File baru dideteksi dan dikonversi dalam hitungan detik
  • File asli tetap utuh; SVG disimpan di folder output Anda
  • Ideal untuk drive bersama, folder ekspor, dan alur aset

Konversi Massal

Berhenti mengonversi gambar satu per satu. Impor seluruh pustaka Anda - 10, 100, atau lebih file PNG, JPG, BMP, atau WebP - dan konversikan semuanya ke SVG dalam sekali jalan.

  • Antrekan ratusan gambar sekaligus
  • Satu profil pengaturan diterapkan ke setiap file
  • Konversi seluruh set ikon dalam satu klik
  • Progres dan hasil dalam satu tampilan yang jelas

Antarmuka Baris Perintah (CLI)

Jalankan konversi dari terminal Anda. CLI memberi Anda kekuatan penuh mesin VTracer dalam satu perintah, sehingga vektorisasi hanya menjadi langkah lain dalam skrip Anda.

  • Konversi dengan satu perintah, tanpa perlu antarmuka
  • Integrasikan ekspor SVG ke dalam skrip build dan alur CI
  • Jadwalkan tugas berulang dengan cron atau Task Scheduler
  • Pengaturan dan kualitas output yang sama seperti aplikasi desktop

Cara Kerja Hot Folder

Siapkan sekali, lalu lupakan - setiap file yang Anda masukkan akan dikonversi dengan sendirinya.

  1. Pilih folder Anda: tentukan folder yang akan dipantau dan ke mana SVG harus disimpan.
  2. Masukkan gambar: simpan atau salin file PNG, JPG, BMP, atau WebP apa pun ke dalam watch folder.
  3. Konversi instan: PixelToPath Pro mendeteksi file baru dan mengonversinya secara otomatis.
  4. Ambil SVG Anda: file vektor yang sudah selesai dan siap digunakan menunggu di folder output Anda.

Pertanyaan yang Sering Diajukan

Apakah saya memerlukan PixelToPath Pro untuk mengonversi gambar?

Tidak. Aplikasi desktop gratis sudah bisa mengonversi file PNG, JPG, BMP, dan WebP ke SVG, offline dan tanpa batas. PixelToPath Pro menambahkan otomatisasi di atasnya: pemantauan hot folder, konversi massal ratusan gambar sekaligus, dan antarmuka baris perintah.

Apa sebenarnya hot folder itu?

Hot folder adalah folder yang terus dipantau oleh PixelToPath Pro. Kapan pun gambar baru muncul di dalamnya - karena Anda menyimpan, menyalin, atau memasukkannya ke sana - aplikasi akan mendeteksinya dan mengonversinya ke SVG secara otomatis, lalu menempatkan hasilnya di folder output yang Anda pilih. Anda tidak perlu membuka aplikasi atau mengklik konversi.

Berapa banyak gambar yang dapat saya konversi sekaligus dengan mode massal?

Anda dapat mengantrekan seluruh pustaka Anda - mengimpor 100 gambar, atau beberapa ratus - dan mengonversi semuanya dalam sekali jalan. Satu-satunya batas adalah perangkat Anda sendiri, karena setiap konversi berjalan secara lokal di CPU Anda dengan mesin VTracer.

Apa yang bisa saya lakukan dengan CLI?

Antarmuka baris perintah memungkinkan Anda mengonversi gambar dengan satu perintah, tanpa membuka antarmuka grafis. Anda dapat mengintegrasikan vektorisasi ke dalam skrip shell, alur build, dan tugas CI, atau menjadwalkan konversi berulang dengan alat seperti cron atau Windows Task Scheduler.

Apakah versi gratis tetap gratis?

Ya. Aplikasi desktop gratis tetap gratis, tak terbatas, dan open source di bawah lisensi MIT. PixelToPath Pro adalah peningkatan opsional untuk alur kerja profesional - aplikasi gratis tidak dibatasi fungsionalitasnya atau dibatasi waktu dengan cara apa pun.

Sistem operasi mana yang didukung oleh PixelToPath Pro?

PixelToPath Pro berjalan di Windows (64-bit) dan Linux, platform yang sama dengan aplikasi desktop gratis. Semuanya berfungsi sepenuhnya offline, persis seperti versi gratis.

Apakah harga €39 sudah termasuk pajak?

Tidak - €39 adalah harga sebelum PPN. Bergantung pada negara Anda dan tempat Anda menyelesaikan pembelian, PPN atau pajak penjualan mungkin ditambahkan saat pembayaran.

Di berapa banyak perangkat saya bisa menginstal PixelToPath Pro?

Lisensi Pro adalah pembelian satu kali: €39 belum termasuk PPN, milik Anda seumur hidup. Ini mencakup satu pengguna dan dapat diaktifkan pada maksimal 3 perangkat - misalnya workstation desktop, laptop, dan komputer studio.
