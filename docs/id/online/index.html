PNG vs SVG, dengan hasil nyata dari alat ini

Di bawah, konversi nyata yang dibuat dengan konverter di halaman ini. Logo mungil 128 px ini, saat diperbesar: PNG larut menjadi piksel persegi sementara SVG yang dilacak tetap sangat tajam.

PNG menyimpan gambar sebagai kisi piksel yang tetap, sehingga hanya terlihat benar pada ukuran saat gambar diekspor: perbesar sebuah logo dan tepinya menjadi buram, tampilkan di layar berdensitas tinggi dan Anda harus mengirim dua atau tiga versi file yang lebih berat dari file yang sama. SVG mendeskripsikan bentuk-bentuk tersebut dengan kurva dan koordinat, sehingga browser menggambar ulangnya dengan tajam di semua ukuran dari satu file kecil. Perbandingan berdampingan di atas menunjukkan hasilnya pada logo sungguhan. Dalam praktiknya: konversikan logo, ikon, line art, dan ilustrasi datar ke SVG, dan simpan foto, tangkapan layar, serta tekstur dalam PNG, WebP, atau JPG, tempat format piksel justru mengompresi lebih baik.

PNG vs SVG secara ringkas

Perbedaan yang sama, dirangkum berdampingan:

Aspek PNG (raster) SVG (vektor)
Penskalaan Buram begitu gambar diperbesar Tajam di semua ukuran, dari 16px hingga 4K
Ukuran file (logo) 40 hingga 80 KB, dan berlipat ganda pada @2x 2 hingga 12 KB, satu file untuk semua layar
Layar berdensitas tinggi Memerlukan ekspor terpisah @1x, @2x, dan @3x Satu file tanpa perubahan
Penyuntingan Piksel yang diratakan: setiap perubahan memerlukan file sumber Setiap bentuk adalah jalur yang dapat diedit
Paling cocok untuk Foto, tangkapan layar, gambar kompleks Logo, ikon, ilustrasi datar

Satu berkas, tiga prasetel

Ketiga SVG adalah konversi nyata dari PNG 512 px ini yang dibuat dengan prasetel konverter ini. Di layar apa pun – favicon 16 px atau tampilan 4K – berkas yang sama tetap tajam.

Vektorisasi Gambar Gratis

PixelToPath adalah alat vektorisasi gambar online gratis: ia mengonversi file PNG, JPG, BMP, atau WebP apa pun menjadi SVG yang bersih dan dapat diskalakan. Teknik ini disebut konversi raster ke vektor atau penelusuran gambar: alih-alih menyimpan satu nilai warna per piksel, mesin membangun kembali gambar Anda sebagai kurva matematis yang digambar ulang oleh browser dengan sempurna di semua ukuran, dari favicon 16px hingga layar 4K. Bitmap menjadi buram setiap kali diperbesar; file vektor tidak pernah. Unggah gambar, saksikan pratinjau langsung diperbarui saat Anda menyempurnakan pengaturan, lalu unduh SVG yang siap untuk Illustrator, Inkscape, dan Figma, untuk disematkan di situs web, atau untuk mesin pemotong laser dan plotter vinil.

Dua mode penelusuran tersedia: warna penuh untuk ilustrasi dan foto, serta hitam & putih untuk logo dan ikon - dengan setiap parameter dapat disesuaikan untuk hasil yang lebih bersih.

Pertanyaan yang Sering Diajukan

Apakah konverter ini benar-benar gratis tanpa batas?

Ya, sepenuhnya gratis. PixelToPath adalah proyek sumber terbuka (Lisensi MIT).

Apakah mendukung gambar berwarna?

Ya. Kami menggunakan VTracer. Pilih prasetel Poster atau Foto.

Apakah file saya disimpan?

Tidak. Segera dihapus dari server setelah konversi selesai.

Format apa saja yang didukung?

PNG, JPG, JPEG, BMP, dan WebP. Anda juga bisa menempelkannya (Ctrl+V).

Berapa ukuran file maksimum?

Online hingga 20 MB. Unduh aplikasi desktop untuk tanpa batas.

Mengapa hasil H&P salah pada gambar berwarna saya?

Aktifkan opsi Balikkan di Pengaturan Lanjutan.

Apa bedanya Spline, Poligon, dan Piksel?

Spline untuk kurva halus. Poligon untuk garis lurus. Piksel untuk batas piksel asli (pixel art).

Bisakah SVG digunakan untuk proyek komersial?

Ya. Tidak ada batasan lisensi sama sekali.
