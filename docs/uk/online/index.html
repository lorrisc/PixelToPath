PNG проти SVG — із реальним результатом інструменту

Нижче — реальна конвертація, виконана конвертером на цій сторінці. Цей крихітний логотип 128 px під збільшенням: PNG розпадається на квадратні пікселі, а векторизований SVG залишається ідеально чітким.

PNG зберігає зображення у вигляді фіксованої сітки пікселів, тому воно виглядає правильно лише в тому розмірі, для якого було експортоване: збільште логотип — краї розмиті, а для екранів із високою щільністю пікселів доводиться постачати дві або три важчі версії того самого файлу. SVG натомість описує ці фігури кривими та координатами, тож браузер перемальовує їх чіткими в будь-якому розмірі з одного невеликого файлу. Порівняння вище показує результат саме на реальному логотипі. На практиці: конвертуйте логотипи, іконки, лінійні малюнки та пласкі ілюстрації в SVG, а фотографії, скріншоти та текстури залишайте в PNG, WebP або JPG — там піксельні формати справді стискаються помітно краще.

PNG проти SVG: наочне порівняння

Та сама різниця, зведена в таблицю:

Критерій PNG (растр) SVG (вектор)
Масштабування Розмивається, щойно зображення збільшують Чіткий у будь-якому розмірі, від 16px до 4K
Розмір файлу (логотип) Від 40 до 80 КБ, а за @2x — удвічі більше Від 2 до 12 КБ, один файл для всіх екранів
Екрани з високою щільністю пікселів Потрібні окремі версії @1x, @2x і @3x Один незмінний файл
Редагування Пікселі зведені в один шар: будь-яка зміна потребує вихідного файлу Кожна фігура — контур, який можна редагувати
Найкраще для Фото, скріншоти, складні зображення Логотипи, іконки, пласкі ілюстрації

Один файл, три пресети

Усі три SVG — реальні конвертації цього PNG 512 px пресетами цього конвертера. На будь-якому екрані — фавіконі 16 px чи дисплеї 4K — той самий файл залишається чітким.

Безкоштовний Векторизатор Зображень

PixelToPath — безкоштовний онлайн-векторизатор зображень: він конвертує будь-який файл PNG, JPG, BMP або WebP у чистий масштабований SVG. Сама технологія називається растрово-векторною конвертацією або трасуванням зображення: замість зберігання одного значення кольору для кожного пікселя рушій наново будує ваше зображення з математичних кривих, які браузер ідеально перемальовує в будь-якому розмірі — від фавікону 16px до дисплея 4K. Растровий файл розмивається під час кожного збільшення; векторний — ніколи. Завантажте зображення, стежте, як попередній перегляд наживо оновлюється, поки ви налаштовуєте параметри, а потім збережіть SVG, готовий для Illustrator, Inkscape та Figma, для вставлення на сайт або для лазерного різака та вінільного плоттера.

Доступні два режими трасування: повнокольоровий для ілюстрацій і фотографій та чорно-білий для логотипів і іконок — при цьому кожен параметр можна налаштувати для чистішого результату.

Часті запитання

Це дійсно безкоштовно та без лімітів?

Так, повністю безкоштовно (ліцензія MIT).

Чи підтримуються кольорові зображення?

Так. Ми використовуємо VTracer. Оберіть пресет Постер або Фото.

Чи зберігаються мої файли?

Ні. Вони видаляються одразу після обробки.

Які формати підтримуються?

PNG, JPG, JPEG, BMP і WebP. (Ctrl+V також працює).

Який максимальний розмір файлу?

В онлайні до 20 МБ. Для більших завантажте десктопний додаток.

Чому Ч/Б результат має поганий вигляд?

Увімкніть Інвертувати у додаткових налаштуваннях.

У чому різниця між режимами Сплайн, Полігон і Піксель?

Сплайн для плавних кривих. Полігон для прямих. Піксель для піксель-арту.

Чи можна використовувати SVG у комерційних цілях?

Так, без ліцензійних обмежень.
