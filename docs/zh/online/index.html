PNG 对比 SVG：工具的真实输出

下面是使用本页转换器完成的一次真实转换。把这个小小的 128 px 徽标放大：PNG 碎裂成一个个方形像素，而描摹出的 SVG 依然完全清晰。

PNG 把图像存储为固定的像素网格，因此只有在导出时的那个尺寸下看起来才正常：放大徽标，边缘就会模糊；要在高密度屏幕上显示，就得为同一个文件再交付两三个更重的版本。SVG 则改用曲线和坐标来描述这些形状，浏览器凭借一个小文件，就能在任何尺寸下——从网站图标到 4K 屏幕——把它们重绘得清晰锐利。上方的左右对比展示的就是它在真实徽标上的效果。实践中：把徽标、图标、线稿和扁平插画转换为 SVG，而照片、截图和纹理则保留为 PNG、WebP 或 JPG——在这些图像上，像素格式反而压缩得更好。

对比项 PNG（位图） SVG（矢量）

免费图像矢量化工具

PixelToPath 是一款免费的在线图像矢量化工具：可将任何 PNG、JPG、BMP 或 WebP 文件转换为干净、可缩放的 SVG。这项技术被称为位图转矢量或图像描摹：引擎不为每个像素存储一个颜色值，而是把您的图像重建为数学曲线，浏览器因此能在任何尺寸下完美重绘——从 16 px 网站图标到 4K 屏幕。位图每次放大都会模糊，矢量文件永远不会。上传图像，一边微调设置一边观察实时预览的变化，然后下载一份随时可用的 SVG——在 Illustrator、Inkscape 和 Figma 中编辑、嵌入网站，或交给激光切割机和刻字机加工，都毫无问题。

提供两种描摹模式：插画和照片使用全彩，徽标和图标使用黑 & 白 - 每个参数均可调节，以获得更干净的结果。

你应该使用哪个预设？

PixelToPath 提供三种优化的预设。您也可以手动微调每个参数。

黑白 黑白

在矢量化之前将图像转换为灰度。非常适合：

  • Logo 和品牌标志
  • 图标和象形图
  • 线条画和草图
  • 刻字和激光雕刻

海报 扁平色彩

以高精度将图像追踪为多个堆叠的颜色图层。非常适合：

  • 扁平插画和卡通
  • 信息图表
  • 剪贴画
  • 数字艺术

照片 摄影照片

使用更广泛的颜色分组和噪点过滤来处理复杂的真实照片。非常适合：

  • 肖像和人脸
  • 风景照片
  • 产品照片
  • 渐变较多的复杂图像

常见问题

这个工具真的是免费无限制的吗？

是的，完全免费。PixelToPath 是开源项目 (MIT)。

是否支持彩色图像？

支持。我们使用 VTracer 引擎。彩色请选择 海报 或 照片。

我的文件会被保存吗？

不会。文件在处理完成后会立即被删除。

支持哪些格式？

PNG、JPG、JPEG、BMP 和 WebP (也支持 Ctrl+V)。

最大文件大小是多少？

在线版最大 20 MB。处理大文件请下载 桌面应用。

为什么彩色图片的黑白结果看起来不对？

请在高级设置中开启 反色。

样条曲线、多边形和像素模式有什么区别？

样条曲线 适合平滑曲线。多边形 适合直线。像素 适合像素画。

我可以用于商业项目吗？

可以，没有任何许可限制。
