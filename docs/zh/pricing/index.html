价格常见问题解答

在线转换器真的是免费的吗？

是的。在线工具无限制使用，也无需帐户。它与所有其他版本使用相同的引擎 — 免费就是免费，输出上没有水印。

Pro 许可证是订阅制吗？

不是。桌面应用 Pro 是一次性支付 39 欧元 (不含增值税) 获取的终身许可证：1 名用户，最多可在 3 台计算机上使用。没有定期费用。

API 积分会过期吗？

不会。购买的积分会保留在您的帐户中，直到您使用它们。每个帐户每月还有 10 次免费转换次数，会在消耗积分前优先使用。

付款是如何处理的？

所有付款都通过 Lemon Squeezy 作为商户记录进行：信用卡、Apple Pay 或 PayPal，增值税/销售税会自动计算，发票也会通过电子邮件发送。

我可以稍后升级吗？

随时可以。免费版本没有时间限制。当您的需求增长时可以随时购买 Pro 或 API 积分 — 它们全都使用相同的转换引擎。
