常见问题解答

我需要 PixelToPath Pro 来转换图片吗？

不需要。免费的桌面应用已经可以离线且无限制地将 PNG、JPG、BMP 和 WebP 文件转换为 SVG。PixelToPath Pro 增加了额外的自动化功能：Hot Folder 监控、一次性批量转换数百张图片，以及命令行界面。

Hot Folder 到底是什么？

Hot Folder 是 PixelToPath Pro 持续监控的一个文件夹。每当有新图片出现在里面——无论是因为您保存、复制还是拖放进来的——应用都会检测到它，并自动将其转换为 SVG，然后将结果放到您选择的输出文件夹中。您无需打开应用或点击转换。

在批量模式下，我一次可以转换多少张图片？

您可以对整个库进行排队——导入 100 张甚至数百张图片——并在一次运行中转换它们。唯一的限制就是您自己的设备，因为每次转换都是在您的 CPU 上使用 VTracer 引擎本地运行的。

我可以用 CLI 做什么？

命令行界面允许您使用单条命令转换图片，而无需打开图形界面。您可以将矢量化集成到 shell 脚本、构建流水线和 CI 任务中，或者使用 cron 或 Windows 任务计划程序等工具安排定期转换。

免费版会一直免费吗？

是的。免费的桌面应用根据 MIT 许可证保持免费、无限制且开源。PixelToPath Pro 是专为专业工作流提供的可选升级，免费版并未以任何方式被限制或缩水。

PixelToPath Pro 支持哪些操作系统？

PixelToPath Pro 在 Windows (64位) 和 Linux 上运行，支持与免费桌面应用相同的平台。所有功能都在完全离线的状态下工作，与免费版完全一样。
