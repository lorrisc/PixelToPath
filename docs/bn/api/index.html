API

PixelToPath API

একটি REST কল দিয়ে প্রোগ্রামাটিকভাবে ছবিগুলিকে ভেক্টরাইজ করুন। একটি PNG, JPG, BMP বা WebP ফাইল আপলোড করুন, এবং একটি পরিষ্কার, প্রোডাকশন-রেডি SVG ফিরে পান। সাদাকালো লাইন আর্ট Potrace দ্বারা ট্রেস করা হয়, রঙিন ছবিগুলি VTracer দ্বারা — বিনামূল্যে অনলাইন কনভার্টারের মতো একই ইঞ্জিন।

আপনার API কি (key) পান পোর্টালে সাইন ইন করুন ডক্স পড়ুন ↓

দ্রুত শুরু

মাত্র তিনটি ধাপে আপনি আপনার টার্মিনাল, স্ক্রিপ্ট বা অ্যাপ থেকে ছবিগুলিকে SVG-তে রূপান্তর করতে পারবেন।

১ · আপনার অ্যাকাউন্ট তৈরি করুন

আপনার ইমেইল এবং একটি পাসওয়ার্ড (১০+ অক্ষর) দিয়ে ক্লায়েন্ট পোর্টালে নিবন্ধন করুন। কোনো ক্রেডিট কার্ডের প্রয়োজন নেই।

২ · একটি API কি তৈরি করুন

পোর্টালে একটি কি (key) তৈরি করুন। এটি একবারই দেখানো হবে — সাবধানে সংরক্ষণ করুন। কি-গুলি দেখতে ptp_live_… এর মতো এবং যে কোনো সময় প্রত্যাহার (revoke) করা যেতে পারে।

৩ · কল করুন /v1/convert

আপনার ছবিটিকে multipart/form-data হিসাবে পাঠান, Authorization হেডারে আপনার কি (key) দিয়ে। SVG রেসপন্স বডিতে ফিরে আসবে।

আপনার প্রথম রূপান্তর

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

ইন্টারঅ্যাক্টিভ রেফারেন্স: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

প্রমাণীকরণ (Authentication)

প্রতিটি রিকোয়েস্ট Authorization হেডারে একটি Bearer টোকেন দিয়ে প্রমাণীকৃত হয়:

Authorization: Bearer ptp_live_0123abc…
  • কি (keys) হলো গোপনীয়: এগুলি সার্ভার-সাইডে হ্যাশ করে সংরক্ষিত থাকে এবং তৈরি করার সময় শুধুমাত্র একবারই দেখানো হয়। কি হারিয়ে গেছে? এটি প্রত্যাহার করুন এবং একটি নতুন কি তৈরি করুন।
  • এক অ্যাকাউন্ট, একাধিক কি: আপনার প্রোজেক্টগুলিকে আলাদা রাখতে ৫টি পর্যন্ত সক্রিয় কি তৈরি করুন। আপনার মাসিক ফ্রি কোটা প্রতি অ্যাকাউন্টের ভিত্তিতে গণনা করা হয়, প্রতি কি-এর ভিত্তিতে নয়।
  • তাত্ক্ষণিক প্রত্যাহার: একটি প্রত্যাহার করা কি অবিলম্বে কাজ করা বন্ধ করে দেয়, তা পোর্টাল থেকেই হোক বা নিষিদ্ধ অ্যাকাউন্টের API রেসপন্স থেকে।

POST /v1/convert

একটি একক স্টেটলেস কলে আপলোড + রূপান্তর। একটি সফল কলে সর্বাধিক ১টি ক্রেডিট খরচ হয় — ব্যর্থ, অবৈধ বা রেট-লিমিটেড কলে কোনো খরচ হয় না।

রিকোয়েস্ট (multipart/form-data)

ফিল্ড টাইপ ডিফল্ট বিবরণ
file file — রূপান্তর করার ছবি। PNG, JPEG, BMP বা WebP · সর্বাধিক ২০ MB · সর্বাধিক ৫০ Mpx · সর্বনিম্ন ৬৪×৬৪ px।
colormode string color <code>color</code> VTracer ইঞ্জিন ব্যবহার করে, <code>binary</code> Potrace (সাদাকালো) ব্যবহার করে।
mode string spline শুধুমাত্র কালার (VTracer) — বাইনারি মোডে উপেক্ষিত। spline | polygon | none
hierarchical string stacked শুধুমাত্র কালার (VTracer) — বাইনারি মোডে উপেক্ষিত। stacked | cutout
filter_speckle int 4 শুধুমাত্র কালার (VTracer) — বাইনারি মোডে উপেক্ষিত। 0–16 — ছোট নয়েজের দাগ সরায়।
color_precision int 6 শুধুমাত্র কালার (VTracer) — বাইনারি মোডে উপেক্ষিত। 1–8 — প্রতি রঙ চ্যানেলে তাৎপর্যপূর্ণ বিট সংখ্যা।
layer_difference int 16 শুধুমাত্র কালার (VTracer) — বাইনারি মোডে উপেক্ষিত। 0–64 — রঙের স্তরগুলির মধ্যে দূরত্ব।
corner_threshold int 60 0–180 — কোণা শনাক্তকরণের কোণ (উভয় ইঞ্জিন)।
length_threshold float 4.0 3.5–10 — সেগমেন্টের সর্বনিম্ন দৈর্ঘ্য (উভয় ইঞ্জিন)।
splice_threshold int 45 0–180 — পথ বিভাজনের কোণ (উভয় ইঞ্জিন)।
path_precision int 3 0–8 — পথের স্থানাঙ্কে দশমিক সংখ্যা।
invert bool false শুধুমাত্র বাইনারি (Potrace) — কালার মোডে উপেক্ষিত। অন্ধকার অংশের পরিবর্তে আলোকিত অংশগুলি ট্রেস করে।
turdsize int 2 শুধুমাত্র বাইনারি (Potrace) — কালার মোডে উপেক্ষিত। 0–20 — এই আকার পর্যন্ত দাগ দমন করে।
alphamax float 1.0 শুধুমাত্র বাইনারি (Potrace) — কালার মোডে উপেক্ষিত। 0–1.334 — কোণা মসৃণকরণের সীমা।
opttolerance float 0.2 শুধুমাত্র বাইনারি (Potrace) — কালার মোডে উপেক্ষিত। 0–10 — বক্ররেখা অপ্টিমাইজেশনের সহনশীলতা।

দুটি ইঞ্জিন, "colormode" দ্বারা নির্বাচিত

API বিনামূল্যে অনলাইন কনভার্টার এবং ডেস্কটপ অ্যাপের মতো একই ইঞ্জিন চালায়:

binary — Potrace

লাইন আর্ট, স্ক্যান, স্কেচ এবং লোগোগুলির সাদাকালো ট্রেসিং। ছবির অন্ধকার অংশ (গ্রেস্কেল < ৫০%) একটি সাদা ব্যাকগ্রাউন্ডে ট্রেস করা হয়। turdsize (নয়েজ রিমুভাল), alphamax (কর্নার স্মুদিং) এবং opttolerance (পাথ অপ্টিমাইজেশন) দিয়ে আউটপুট নিখুঁত করুন।

color — VTracer

ইলাস্ট্রেশন, কার্টুন এবং ছবির জন্য লেয়ার করা রঙিন ভেক্টরাইজেশন। filter_speckle, color_precision, layer_difference দিয়ে ডিটেল লেভেল এবং mode (spline, polygon, none) দিয়ে কার্ভ ফিটিং নিয়ন্ত্রণ করুন।

ছবিগুলি ঠিক ওয়েবসাইটের মতোই প্রি-প্রসেস করা হয়: রূপান্তরের আগে দীর্ঘতম দিকটিকে ১৫০০ px-এ রিসাইজ করা হয়, এবং API X-Detected-Type হেডারে শনাক্ত করা ছবির টাইপ (line_art, logo, photo বা illustration) প্রদান করে।

রেসপন্স

সফল হলে: 200 OK সাথে image/svg+xml — বডিতে থাকে আসল SVG ফাইলটি। তথ্যমূলক হেডারগুলি:

হেডার বিবরণ
X-Credits-Remainingএই কলের চার্জ কাটার পর, অ্যাকাউন্টে অবশিষ্ট পেইড ক্রেডিট।
X-Free-Remainingএই মাসে অবশিষ্ট ফ্রি রূপান্তর।
X-Detected-Typeশনাক্ত করা ছবির টাইপ (তথ্য): line_art, logo, photo বা illustration।
X-Processing-Timeসার্ভার প্রসেসিং সময়, সেকেন্ডে।

GET /v1/me

এটি কল করতে ব্যবহৃত কি (key)-এর অ্যাকাউন্টের অবস্থা। বিনামূল্যে — কখনো আপনার কোটা থেকে গণনা করা হয় না, কখনো চার্জ করা হয় না।

উদাহরণ রেসপন্স

GET /v1/me
Authorization: Bearer ptp_live_…

{
  "key": { "name": "prod", "prefix": "ptp_live_0123abc", … },
  "usage": {
    "month": "2026-09", "free_used": 7, "free_limit": 10,
    "free_remaining": 3, "resets_at": "2026-10-01T00:00:00+00:00"
  },
  "credits": { "balance": 120 }
}

ত্রুটি (Errors)

প্রতিটি ত্রুটি একটি সুসংগত JSON এনভেলপ প্রদান করে। ব্যর্থ কলগুলিতে কখনো ক্রেডিট খরচ হয় না।

HTTP/1.1 402 Payment Required
{
  "error": {
    "code": "quota_exceeded",
    "message": "Monthly free quota used and no credits left.",
    "usage": { "free_used": 10, "free_limit": 10, "credits": 0 }
  }
}
HTTP কোড কখন
401invalid_api_keyঅনুপস্থিত, ত্রুটিপূর্ণ, অজানা বা প্রত্যাহার করা API কি।
402quota_exceededমাসিক ফ্রি কোটা শেষ এবং কোনো ক্রেডিট অবশিষ্ট নেই।
403account_bannedঅ্যাকাউন্টটি নিষিদ্ধ করা হয়েছে — এর সমস্ত কি প্রত্যাখ্যান করা হবে।
403ip_blockedকলার IP ব্লক করা আছে।
413file_too_largeফাইল ২০ MB এর চেয়ে বড়।
422invalid_image / image_too_small / invalid_paramsঅবৈধ ছবি, ছবি খুব ছোট বা অবৈধ প্যারামিটার মান।
429rate_limitedপ্রতি-কি রেট লিমিট অতিক্রম করেছে (নিচে দেখুন)। একটি Retry-After হেডার অন্তর্ভুক্ত থাকে।
500internal_errorসার্ভার-সাইডে রূপান্তর ব্যর্থ হয়েছে — কোনো ক্রেডিট কাটা হয় না।

রেট লিমিট

লিমিটগুলি প্রতি API কি-তে প্রযোজ্য, প্রতি IP-তে নয়, তাই অন্য কারও ট্রাফিকের জন্য একটি শেয়ার করা অফিস বা CI রানার কখনো শাস্তি পাবে না।

মূল্য (Pricing)

প্রতিটি নতুন অ্যাকাউন্ট প্রতি মাসে ১০টি ফ্রি রূপান্তর পায়, কোনো ক্রেডিট কার্ডের প্রয়োজন নেই। আরও প্রয়োজন? প্রিপেইড ছবি কিনুন — যেকোনো পরিমাণ (৫০-এর ব্যাচে), ভলিউম ডিসকাউন্ট সহ। এগুলোর মেয়াদ কখনো শেষ হয় না এবং আপনার মাসিক ফ্রি কোটার সাথে যুক্ত হয় (আগে ফ্রি রূপান্তরগুলি ব্যবহৃত হয়)।

কোডের উদাহরণ

কপি-পেস্ট এবং সংশোধন করুন। API সাধারণ multipart/form-data ব্যবহার করে, তাই যেকোনো HTTP ক্লায়েন্ট কাজ করে।

cURL

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "colormode=color" \
  -F "filter_speckle=4" \
  -o photo.svg

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

প্রায়শই জিজ্ঞাসিত প্রশ্নাবলী (FAQ)

একটি রূপান্তর হিসেবে কী গণনা করা হয়?

একটি সফল POST /v1/convert কল যা একটি SVG প্রদান করে। ব্যর্থ কলগুলি (অবৈধ ছবি, ভুল প্যারামিটার, রেট লিমিটেড, সার্ভার ত্রুটি) এবং GET /v1/me কলগুলিতে কখনো চার্জ করা হয় না।

মাসিক ফ্রি কোটা কীভাবে গণনা করা হয়?

প্রতি অ্যাকাউন্টে, UTC ক্যালেন্ডার মাসের ভিত্তিতে — এটি ১ তারিখে 00:00 UTC-তে রিসেট হয়। একাধিক API কি তৈরি করলে ফ্রি কোটা গুণিত হয় না: একটি অ্যাকাউন্টের সমস্ত কি একই ১০টি ফ্রি রূপান্তর শেয়ার করে।

ক্রেডিটগুলির কি মেয়াদ শেষ হয়?

না। আপনার কেনা ক্রেডিটগুলি ব্যবহার না করা পর্যন্ত আপনার অ্যাকাউন্টে থাকে। আপনার ১০টি ফ্রি মাসিক রূপান্তর শেষ হওয়ার পরেই কেবল এগুলি ব্যবহৃত হয়।

আমি এক মাসে আরও রূপান্তর কীভাবে পেতে পারি?

ক্লায়েন্ট পোর্টাল থেকে প্রিপেইড ছবি কিনুন — যেকোনো পরিমাণ, ৫০-এর ব্যাচে। আপনি সর্বদা ঠিক কতগুলি ছবি পাবেন তা দেখতে পান: ৫০টি ছবি €২.৫০, ৫০০টি ছবি €২০, ২,৫০০টি €৭৫, ১০,০০০টি €২০০, ৫০,০০০টি €৫০০। পেমেন্টের কয়েক সেকেন্ডের মধ্যেই ক্রেডিটগুলি আপনার অ্যাকাউন্টে স্বয়ংক্রিয়ভাবে যোগ করা হয় — কোনো লাইসেন্স কি নেই, কিছু প্রবেশ করার নেই।

আমার API কি হারিয়ে গেলে কী হবে?

কিগুলি হ্যাশ করে সংরক্ষণ করা হয়, তাই সেগুলি পুনরুদ্ধার করা যায় না। পোর্টালে হারিয়ে যাওয়া কি-টি প্রত্যাহার করুন এবং একটি নতুন তৈরি করুন — এটি অবিলম্বে কার্যকর হয়।

কোন কোন ইমজে ফরম্যাট সমর্থিত?

PNG, JPEG, BMP এবং WebP, ২০ MB এবং ৫০ মেগাপিক্সেল পর্যন্ত, ন্যূনতম ৬৪×৬৪ পিক্সেল। ১৫০০ পিক্সেলের চেয়ে বড় দিকযুক্ত ছবিগুলি রূপান্তরের আগে রিসাইজ করা হয়, ঠিক বিনামূল্যে ওয়েবসাইটের মতোই।
