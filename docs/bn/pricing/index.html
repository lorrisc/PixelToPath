আপনি যেগুলোর জন্য পে করেন না

এই পেজের প্রতিটি মূল্যই সম্পূর্ণ মূল্য। আপনার বিলে যেগুলি কখনও আসবে না:

  • পুনরাবৃত্তিমূলক কিছু নেই — অনলাইন টুল এবং ডেস্কটপ অ্যাপ সারাজীবনের জন্য বিনামূল্যে, Pro হলো এককালীন পেমেন্ট, এবং API প্রিপেইড ক্রেডিটে চলে যার মেয়াদ কখনও শেষ হয় না।
  • শুরু করতে কোনো অ্যাকাউন্ট বা ক্রেডিট কার্ড লাগে না — সাইন আপ না করেই ব্রাউজারে রূপান্তর করুন, এবং API ফ্রি টিয়ারে শুধুমাত্র একটি ইমেইল লাগে।
  • কখনো কোনো ওয়াটারমার্ক নেই — আপনি যে SVG-টি ডাউনলোড করেন তা বিনামূল্যে বা পেইড সংস্করণ যেখান থেকেই আসুক না কেন, তা হুবহু একই রকম।
  • কোনো সারপ্রাইজ চার্জ নেই — চেকআউটের সময় স্বয়ংক্রিয়ভাবে ভ্যাট হিসাব করা হয়, এবং অব্যবহৃত API ক্রেডিট আপনার প্রয়োজন না হওয়া পর্যন্ত অপেক্ষা করে।

মূল্য সংক্রান্ত প্রায়শই জিজ্ঞাসিত প্রশ্নাবলী (FAQ)

অনলাইন কনভার্টার কি সত্যিই বিনামূল্যে?

হ্যাঁ। অনলাইন টুলটি আনলিমিটেড এবং কোনো অ্যাকাউন্টের প্রয়োজন নেই। এটি অন্য সমস্ত সংস্করণের মতোই একই ইঞ্জিন — বিনামূল্যের অর্থ সম্পূর্ণ বিনামূল্যে, আউটপুটে কোনো ওয়াটারমার্ক নেই।

Pro লাইসেন্স কি একটি সাবস্ক্রিপশন?

না। ডেস্কটপ অ্যাপ প্রো (Pro) হলো একটি আজীবন লাইসেন্সের জন্য €৩৯-এর (ভ্যাট বাদে) এককালীন পেমেন্ট: ১ ব্যবহারকারী, সর্বাধিক ৩টি মেশিনে ব্যবহারযোগ্য। কোনো পুনরাবৃত্ত চার্জ নেই।

API ক্রেডিট কি শেষ হয়ে যায়?

না। আপনার কেনা ক্রেডিটগুলি ব্যবহার না করা পর্যন্ত আপনার অ্যাকাউন্টে থাকে। প্রতিটি অ্যাকাউন্ট প্রতি মাসে ১০টি ফ্রি রূপান্তর পায়, যা ক্রেডিটের আগে ব্যবহৃত হয়।

পেমেন্ট কীভাবে পরিচালনা করা হয়?

সমস্ত পেমেন্ট মার্চেন্ট অফ রেকর্ড হিসেবে Lemon Squeezy-এর মাধ্যমে যায়: কার্ড, Apple Pay বা PayPal, ভ্যাট/সেলস ট্যাক্স স্বয়ংক্রিয়ভাবে হিসাব করা হয় এবং ইমেইলের মাধ্যমে একটি ইনভয়েস পাঠানো হয়।

আমি কি পরে আপগ্রেড করতে পারব?

যেকোনো সময়। বিনামূল্যের সংস্করণগুলির কোনো সময়সীমা নেই, এবং আপনার প্রয়োজন বাড়লে যেকোনো সময় Pro বা API ক্রেডিট যোগ করা যেতে পারে — এগুলি সবই একই কনভার্সন ইঞ্জিন ব্যবহার করে।

আজই বিনামূল্যে শুরু করুন

প্রতিটি সংস্করণ বিনামূল্যে শুরু হয়। যেকোনো একটি বেছে নিন এবং কয়েক সেকেন্ডের মধ্যে আপনার প্রথম ছবিটি রূপান্তর করুন।
