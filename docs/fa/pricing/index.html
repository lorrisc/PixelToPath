آنچه بابت آن پولی نمی‌پردازید

تمام قیمت‌های این صفحه قیمت نهایی هستند. مواردی که هرگز در صورتحساب شما نخواهند آمد:

  • بدون هزینه‌های تکرار شونده — ابزار آنلاین و برنامه دسکتاپ برای همیشه رایگان هستند، نسخه Pro با یک بار پرداخت است، و API بر اساس اعتبارهای پیش‌پرداخت‌شده‌ای که هرگز منقضی نمی‌شوند کار می‌کند.
  • بدون نیاز به حساب کاربری یا کارت بانکی برای شروع — در مرورگر بدون ثبت‌نام تبدیل کنید، و سطح رایگان API فقط به یک ایمیل نیاز دارد.
  • بدون هیچ‌گونه واترمارک — فایل SVG دانلودی در نسخه‌های رایگان یا پولی دقیقاً یکسان است.
  • بدون هزینه‌های غافلگیرکننده — مالیات بر ارزش افزوده به طور خودکار در زمان پرداخت محاسبه می‌شود، و اعتبارهای استفاده‌نشده API تا زمان نیاز شما باقی می‌مانند.

سوالات متداول قیمت‌گذاری

آیا مبدل آنلاین واقعاً رایگان است؟

بله. ابزار آنلاین نامحدود است و نیازی به حساب کاربری ندارد. این همان موتور موجود در تمام نسخه‌های دیگر است — رایگان یعنی واقعاً رایگان، بدون واترمارک روی خروجی.

آیا لایسنس Pro یک اشتراک است؟

خیر. برنامه دسکتاپ Pro یک پرداخت یک‌باره ۳۹ یورویی (بدون مالیات) برای یک لایسنس مادام‌العمر است: ۱ کاربر، قابل استفاده روی حداکثر ۳ دستگاه. هیچ هزینه دوره‌ای وجود ندارد.

آیا اعتبارهای API منقضی می‌شوند؟

خیر. اعتبارهای خریداری‌شده تا زمانی که استفاده شوند در حساب شما باقی می‌مانند. همچنین هر حساب دارای ۱۰ تبدیل رایگان در ماه است که قبل از اعتبارها مصرف می‌شوند.

پرداخت‌ها چگونه انجام می‌شوند؟

تمام پرداخت‌ها از طریق Lemon Squeezy به عنوان فروشنده اصلی انجام می‌شوند: کارت بانکی، Apple Pay یا PayPal، محاسبه خودکار مالیات بر ارزش افزوده (VAT) و ارسال فاکتور از طریق ایمیل.

آیا می‌توانم بعداً ارتقا دهم؟

هر زمان که بخواهید. نسخه‌های رایگان هیچ محدودیت زمانی ندارند، و نسخه‌های Pro یا اعتبارهای API می‌توانند هر زمان که نیازهای شما بیشتر شد اضافه شوند — همه آن‌ها از همان موتور تبدیل استفاده می‌کنند.

از امروز رایگان شروع کنید

هر نسخه به صورت رایگان شروع می‌شود. یکی را انتخاب کنید و اولین تصویر خود را در چند ثانیه تبدیل نمایید.
