API

API PixelToPath

Wektoryzuj obrazy z poziomu kodu za pomocą jednego wywołania REST. Prześlij plik PNG, JPG, BMP lub WebP, a otrzymasz gotowy do użycia, czysty plik SVG. Czarno-biała grafika jest wektoryzowana przez Potrace, a kolorowe obrazy przez VTracer — dokładnie te same silniki, co w darmowym konwerterze online.

Szybki start

Tylko trzy kroki dzielą Cię od konwersji obrazów na SVG z Twojego terminala, skryptu lub aplikacji.

1 · Załóż konto

Zarejestruj się w portalu klienta podając e-mail i hasło (min. 10 znaków). Nie wymagamy podpinania karty kredytowej.

2 · Utwórz klucz API

W portalu utwórz klucz. Będzie on wyświetlony tylko raz — zachowaj go w bezpiecznym miejscu. Klucze zaczynają się od ptp_live_… i mogą zostać w każdej chwili unieważnione.

3 · Wywołaj /v1/convert

Wyślij swój obraz jako multipart/form-data, podając swój klucz w nagłówku Authorization. Plik SVG zostanie zwrócony w treści odpowiedzi.

Twoja pierwsza konwersja

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

Interaktywna dokumentacja: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

Uwierzytelnianie

Każde żądanie jest uwierzytelniane za pomocą tokena Bearer w nagłówku Authorization:

Authorization: Bearer ptp_live_0123abc…
  • Klucze są tajne: są przechowywane na serwerze w formie zaszyfrowanej i wyświetlane tylko raz przy tworzeniu. Zgubiłeś klucz? Unieważnij go i stwórz nowy.
  • Jedno konto, kilka kluczy: utwórz do 5 aktywnych kluczy, aby oddzielić różne projekty. Twój miesięczny darmowy limit jest liczony na całe konto, a nie na pojedynczy klucz.
  • Natychmiastowe unieważnienie: unieważniony klucz natychmiast przestaje działać, zarówno z poziomu portalu, jak i w odpowiedziach API dla zbanowanego konta.

POST /v1/convert

Przesłanie pliku i konwersja podczas jednego bezstanowego wywołania. Jedno udane wywołanie kosztuje najwyżej 1 kredyt — nieudane, nieprawidłowe lub zablokowane z powodu limitu wywołania są darmowe.

Żądanie (multipart/form-data)

Pole Typ Domyślnie Opis
file file — Obraz do konwersji. PNG, JPEG, BMP lub WebP · max 20 MB · max 50 Mpx · min 64×64 px.
colormode string color <code>color</code> korzysta z silnika VTracer, <code>binary</code> z Potrace (czarno-białe).
mode string spline Tylko dla trybu koloru (VTracer) — ignorowane w trybie binarnym. spline | polygon | none
hierarchical string stacked Tylko dla trybu koloru (VTracer) — ignorowane w trybie binarnym. stacked | cutout
filter_speckle int 4 Tylko dla trybu koloru (VTracer) — ignorowane w trybie binarnym. 0–16 — usuwa małe plamy szumu.
color_precision int 6 Tylko dla trybu koloru (VTracer) — ignorowane w trybie binarnym. 1–8 — liczba istotnych bitów na kanał koloru.
layer_difference int 16 Tylko dla trybu koloru (VTracer) — ignorowane w trybie binarnym. 0–64 — odległość między warstwami kolorów.
corner_threshold int 60 0–180 — kąt wykrywania narożników (oba silniki).
length_threshold float 4.0 3.5–10 — minimalna długość segmentu (oba silniki).
splice_threshold int 45 0–180 — kąt dzielenia ścieżek (oba silniki).
path_precision int 3 0–8 — miejsca dziesiętne we współrzędnych ścieżki.
invert bool false Tylko dla trybu binarnego (Potrace) — ignorowane w trybie koloru. Wektoryzacja jasnych obszarów zamiast ciemnych.
turdsize int 2 Tylko dla trybu binarnego (Potrace) — ignorowane w trybie koloru. 0–20 — tłumi plamy do tej wielkości.
alphamax float 1.0 Tylko dla trybu binarnego (Potrace) — ignorowane w trybie koloru. 0–1.334 — próg wygładzania narożników.
opttolerance float 0.2 Tylko dla trybu binarnego (Potrace) — ignorowane w trybie koloru. 0–10 — tolerancja optymalizacji krzywych.

Dwa silniki, wybierane przez "colormode"

API używa dokładnie tych samych silników, co darmowy konwerter online i aplikacja desktopowa:

binary (binarny) — Potrace

Czarno-biała wektoryzacja rysunków zarysowych, skanów, szkiców i logo. Ciemna część obrazu (odcienie szarości < 50%) jest wektoryzowana na białym tle. Precyzyjnie dostosuj efekt końcowy za pomocą turdsize (usuwanie szumów), alphamax (wygładzanie narożników) oraz opttolerance (optymalizacja ścieżek).

color (kolor) — VTracer

Warstwowa, kolorowa wektoryzacja dla ilustracji, kreskówek i zdjęć. Kontroluj poziom szczegółowości za pomocą filter_speckle, color_precision, layer_difference oraz dopasowania krzywych za pomocą mode (spline, polygon, none).

Obrazy są wstępnie przetwarzane dokładnie tak, jak na stronie internetowej: najdłuższy bok jest zmniejszany do 1500 pikseli przed konwersją, a API zwraca wykryty typ obrazu (line_art, logo, photo lub illustration) w nagłówku X-Detected-Type.

Odpowiedź

W przypadku sukcesu: 200 OK z image/svg+xml — sama odpowiedź zawiera plik SVG. Informacyjne nagłówki:

Nagłówek Opis
X-Credits-RemainingPozostałe płatne kredyty na koncie, po odliczeniu kosztu za obecne wywołanie.
X-Free-RemainingDarmowe konwersje pozostałe w tym miesiącu.
X-Detected-TypeWykryty typ obrazu (informacyjnie): line_art, logo, photo lub illustration.
X-Processing-TimeCzas przetwarzania serwera w sekundach.

Limity wywołań

Limity są stosowane na poziomie klucza API, nie na adres IP. Dzięki temu współdzielone biuro czy narzędzia CI nigdy nie są blokowane przez ruch innej osoby.

Cennik

Każde nowe konto otrzymuje 10 darmowych konwersji każdego miesiąca, nie wymagamy podania karty kredytowej. Potrzebujesz więcej? Kup pakiety przedpłacone na obrazy — dowolną ilość (w pakietach po 50), ze zniżkami ilościowymi. Nigdy nie wygasają i łączą się z miesięcznym, darmowym limitem (darmowe konwersje są zużywane jako pierwsze).

Przykłady kodu

Skopiuj, wklej i dopasuj. API korzysta z formatu multipart/form-data, więc można go używać z dowolnym klientem HTTP.

cURL

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "colormode=color" \
  -F "filter_speckle=4" \
  -o photo.svg

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

Często zadawane pytania

Co liczy się jako jedna konwersja?

Jedno udane żądanie POST /v1/convert, które zwróci plik SVG. Nieudane wywołania (zły plik, błędne parametry, limit zapytań, błąd serwera) oraz wywołania GET /v1/me nigdy nie pobierają kredytu.

Jak liczony jest miesięczny darmowy pakiet?

Dla całego konta, według kalendarza UTC — limit odnawia się pierwszego dnia miesiąca o północy (00:00 UTC). Tworzenie kilku kluczy API nie powiększa darmowej puli: wszystkie klucze z danego konta dzielą te same 10 darmowych konwersji.

Czy kredyty tracą ważność?

Nie. Zakupione kredyty zostają na koncie tak długo, aż z nich nie skorzystasz. Będą zużywane dopiero wtedy, gdy wykorzystasz pakiet 10 darmowych konwersji na dany miesiąc.

Jak uzyskać więcej konwersji w miesiącu?

Kup przedpłacone obrazy w portalu dla klientów — dowolną liczbę, w paczkach po 50. Zawsze dokładnie widzisz, ile obrazów otrzymujesz: 50 obrazów za 2,50 €, 500 obrazów za 20 €, 2 500 za 75 €, 10 000 za 200 €, 50 000 za 500 €. Kredyty są dodawane do konta automatycznie w ciągu kilku sekund od dokonania płatności — bez kluczy licencyjnych, niczego nie trzeba wpisywać ręcznie.

Co się stanie, jeśli zgubię klucz API?

Klucze są zaszyfrowane na serwerze, więc nie można ich odzyskać. Unieważnij utracony klucz w portalu i utwórz nowy — zmiana zostaje wdrożona natychmiast.

Jakie formaty obrazów są obsługiwane?

PNG, JPEG, BMP i WebP, o rozmiarze do 20 MB i do 50 megapikseli, a także co najmniej 64×64 pikseli. Obrazy o wymiarach większych niż 1500 px (najdłuższy bok) są zmniejszane przed konwersją, dokładnie tak samo jak na bezpłatnej stronie internetowej.
