जिसके लिए आप भुगतान नहीं करते हैं

इस पृष्ठ पर प्रत्येक मूल्य पूर्ण मूल्य है। आपके बिल पर जो कभी दिखाई नहीं देता:

  • कुछ भी आवर्ती (recurring) नहीं — ऑनलाइन टूल और डेस्कटॉप ऐप हमेशा के लिए मुफ़्त हैं, Pro एक बार का भुगतान है, और API उन प्रीपेड क्रेडिट पर चलती है जो कभी समाप्त नहीं होते हैं।
  • शुरू करने के लिए कोई खाता या क्रेडिट कार्ड नहीं — साइन अप किए बिना ब्राउज़र में कनवर्ट करें, और API का मुफ़्त टियर केवल एक ईमेल मांगता है。
  • कोई वॉटरमार्क नहीं, कभी नहीं — आप जो SVG डाउनलोड करते हैं वह बिल्कुल समान होता है, चाहे वह मुफ़्त या सशुल्क संस्करण से आया हो।
  • कोई आश्चर्यजनक शुल्क नहीं — चेकआउट के समय वैट (VAT) की स्वचालित रूप से गणना की जाती है, और अप्रयुक्त API क्रेडिट बस तब तक प्रतीक्षा करते हैं जब तक आपको उनकी आवश्यकता न हो।

मूल्य निर्धारण संबंधी अक्सर पूछे जाने वाले प्रश्न

क्या ऑनलाइन कनवर्टर वास्तव में मुफ़्त है?

हाँ। ऑनलाइन टूल असीमित है और इसके लिए किसी खाते की आवश्यकता नहीं है। यह हर दूसरे संस्करण के समान इंजन है — मुफ़्त का मतलब मुफ़्त है, आउटपुट पर कोई वॉटरमार्क नहीं है।

क्या Pro लाइसेंस एक सदस्यता है?

नहीं। डेस्कटॉप ऐप Pro एक आजीवन लाइसेंस के लिए €39 (वैट रहित) का एक बार का भुगतान है: 1 उपयोगकर्ता, अधिकतम 3 मशीनों पर उपयोग करने योग्य। कोई आवर्ती शुल्क नहीं है।

क्या API क्रेडिट समाप्त (एक्सपायर) होते हैं?

नहीं। खरीदे गए क्रेडिट आपके उपयोग करने तक आपके खाते में रहते हैं। प्रत्येक खाते को हर महीने 10 मुफ़्त रूपांतरण भी मिलते हैं, जिनका उपयोग क्रेडिट से पहले किया जाता है।

भुगतान कैसे संभाले जाते हैं?

सभी भुगतान रिकॉर्ड के व्यापारी के रूप में Lemon Squeezy के माध्यम से जाते हैं: कार्ड, Apple Pay या PayPal, वैट/बिक्री कर की स्वचालित रूप से गणना की जाती है, और ईमेल द्वारा चालान भेजा जाता है।

क्या मैं बाद में अपग्रेड कर सकता हूँ?

कभी भी। मुफ़्त संस्करणों की कोई समय सीमा नहीं है, और आपकी ज़रूरतें बढ़ने पर Pro या API क्रेडिट जोड़े जा सकते हैं — वे सभी एक ही रूपांतरण इंजन का उपयोग करते हैं।

आज ही मुफ़्त शुरू करें

हर संस्करण मुफ़्त शुरू होता है। एक चुनें और सेकंडों में अपनी पहली छवि को कनवर्ट करें।
