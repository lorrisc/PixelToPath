API

PixelToPath API

Vektorisera bilder programmatiskt med ett REST-anrop. Ladda upp en PNG, JPG, BMP eller WebP-fil, få en ren, produktionsklar SVG tillbaka. Svartvit linjekonst spåras av Potrace, färgbilder av VTracer — samma motorer som den kostnadsfria onlinekonverteraren.

Snabbstart

Tre steg och du konverterar bilder till SVG från din terminal, dina skript eller din app.

1 · Skapa ditt konto

Registrera dig på kundportalen med din e-post och ett lösenord (10+ tecken). Inget kreditkort krävs.

2 · Skapa en API-nyckel

I portalen skapar du en nyckel. Den visas en gång — förvara den säkert. Nycklar ser ut som ptp_live_… och kan återkallas när som helst.

3 · Anropa /v1/convert

Skicka din bild som multipart/form-data med din nyckel i Authorization-huvudet. SVG-filen kommer tillbaka i svarskroppen.

Din första konvertering

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

Interaktiv referens: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

Autentisering

Varje begäran autentiseras med en Bearer-token i Authorization-huvudet:

Authorization: Bearer ptp_live_0123abc…
  • Nycklar är hemligheter: de lagras hashade på serversidan och visas bara en gång vid skapandet. Tappat bort nyckeln? Återkalla den och skapa en ny.
  • Ett konto, flera nycklar: skapa upp till 5 aktiva nycklar för att separera dina projekt. Din månatliga gratiskvot räknas per konto, inte per nyckel.
  • Omedelbar återkallelse: en återkallad nyckel slutar fungera omedelbart, från portalen eller API-svaret för ett bannlyst konto.

POST /v1/convert

Uppladdning + konvertering i ett enda tillståndslöst anrop. Ett framgångsrikt anrop kostar högst 1 kredit — misslyckade, ogiltiga eller hastighetsbegränsade anrop kostar ingenting.

Begäran (multipart/form-data)

Fält Typ Standard Beskrivning
file file — Bilden som ska konverteras. PNG, JPEG, BMP eller WebP · max 20 MB · max 50 Mpx · min 64×64 px.
colormode string color <code>color</code> använder VTracer-motorn, <code>binary</code> använder Potrace (svartvitt).
mode string spline Endast Color (VTracer) — ignoreras i binärt läge. spline | polygon | none
hierarchical string stacked Endast Color (VTracer) — ignoreras i binärt läge. stacked | cutout
filter_speckle int 4 Endast Color (VTracer) — ignoreras i binärt läge. 0–16 — ta bort små brusfläckar.
color_precision int 6 Endast Color (VTracer) — ignoreras i binärt läge. 1–8 — antal signifikanta bitar per färgkanal.
layer_difference int 16 Endast Color (VTracer) — ignoreras i binärt läge. 0–64 — avstånd mellan färglager.
corner_threshold int 60 0–180 — vinkel för hörndetektion (båda motorerna).
length_threshold float 4.0 3,5–10 — minsta segmentlängd (båda motorerna).
splice_threshold int 45 0–180 — vinkel för banfogning (båda motorerna).
path_precision int 3 0–8 — decimaler i bankoordinater.
invert bool false Endast Binary (Potrace) — ignoreras i färgläge. Spåra de ljusa områdena istället för de mörka.
turdsize int 2 Endast Binary (Potrace) — ignoreras i färgläge. 0–20 — undertryck fläckar upp till denna storlek.
alphamax float 1.0 Endast Binary (Potrace) — ignoreras i färgläge. 0–1,334 — tröskelvärde för hörnutjämning.
opttolerance float 0.2 Endast Binary (Potrace) — ignoreras i färgläge. 0–10 — tolerans för kurvoptimering.

Två motorer, valda av "colormode"

API:et kör exakt samma motorer som den kostnadsfria onlinekonverteraren och skrivbordsappen:

binary — Potrace

Svartvit spårning av linjekonst, skanningar, skisser och logotyper. Den mörka delen av bilden (gråskala < 50 %) spåras på en vit bakgrund. Finjustera utdata med turdsize (brusreducering), alphamax (hörnutjämning) och opttolerance (banoptimering).

color — VTracer

Lagerindelad färgvektorisering för illustrationer, tecknat och foton. Kontrollera detaljnivån med filter_speckle, color_precision, layer_difference och kurvanpassningen med mode (spline, polygon, none).

Bilder förbehandlas exakt som på webbplatsen: den längsta sidan ändras till 1500 px före konvertering, och API:et returnerar den upptäckta bildtypen (line_art, logo, photo eller illustration) i huvudet X-Detected-Type.

Svar

Vid framgång: 200 OK med image/svg+xml — kroppen är själva SVG-filen. Informativa huvuden:

Huvud Beskrivning
X-Credits-RemainingBetalda krediter kvar på kontot, efter detta anrops debitering.
X-Free-RemainingGratis konverteringar kvar denna månad.
X-Detected-TypeUpptäckt bildtyp (info): line_art, logo, photo eller illustration.
X-Processing-TimeServerbearbetningstid i sekunder.

Kodexempel

Kopiera, klistra in och anpassa. API:et talar vanlig multipart/form-data, så vilken HTTP-klient som helst fungerar.

cURL

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "colormode=color" \
  -F "filter_speckle=4" \
  -o photo.svg

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

Vanliga frågor

Vad räknas som en konvertering?

Ett framgångsrikt POST /v1/convert-anrop som returnerar en SVG. Misslyckade anrop (ogiltig bild, fel parametrar, hastighetsbegränsad, serverfel) och GET /v1/me-anrop debiteras aldrig.

Hur räknas den månatliga gratiskvoten?

Per konto, enligt UTC-kalendermånaden — den återställs den 1:a kl. 00:00 UTC. Att skapa flera API-nycklar multiplicerar inte gratiskvoten: alla nycklar på ett konto delar på samma 10 gratis konverteringar.

Går krediter ut?

Nej. Köpta krediter ligger kvar på ditt konto tills du använder dem. De förbrukas först efter att dina 10 gratis månatliga konverteringar är slut.

Hur får jag fler konverteringar under en månad?

Köp förbetalda bilder från kundportalen — valfri mängd, i partier om 50. Du ser alltid exakt hur många bilder du får: 50 bilder 2,50 €, 500 bilder 20 €, 2 500 bilder 75 €, 10 000 bilder 200 €, 50 000 bilder 500 €. Krediter läggs automatiskt till på ditt konto inom några sekunder efter betalningen — ingen licensnyckel, inget att knappa in.

Vad händer om jag tappar bort min API-nyckel?

Nycklar lagras hashade, så de kan inte återställas. Återkalla den förlorade nyckeln i portalen och skapa en ny — det träder i kraft omedelbart.

Vilka bildformat stöds?

PNG, JPEG, BMP och WebP, upp till 20 MB och 50 megapixel, minst 64×64 pixlar. Bilder större än 1500 px på sin längsta sida ändras i storlek före konvertering, precis som på den kostnadsfria webbplatsen.
