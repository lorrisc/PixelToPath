無料アプリの全機能に加え、自動化を追加

PixelToPath Proは、無料版と同じVTracerエンジンを使用し、プライバシーも同様に保護されます。すべてはローカル環境で実行されます。変わるのは、手作業の手間がどれだけ省けるかということです。

ホットフォルダ監視

任意のフォルダを自動変換パイプラインに変えます。新しい画像が追加された瞬間にPixelToPath Proがそれを検知し、即座にSVGに変換します。クリックも、待ち時間も、見張る必要もありません。

  • ファイルをドロップするだけで、すぐに使えるSVGが出力されます
  • 新しいファイルは数秒以内に検知され、変換されます
  • 元のファイルはそのまま保持され、出力先フォルダにSVGが保存されます
  • 共有ドライブ、エクスポート用フォルダ、アセットパイプラインに最適です

バッチ変換

画像を1枚ずつ変換するのはもうやめましょう。10枚、100枚、それ以上のPNG、JPG、BMP、WebPファイルなどのライブラリ全体をインポートし、一度の実行で全てSVGに変換します。

  • 数百枚の画像を一度にキューへ追加
  • 1つの設定プロファイルをすべてのファイルに適用
  • アイコンセット全体をワンクリックで変換
  • 進捗と結果を1つのクリアな画面で確認

コマンドラインインターフェース (CLI)

ターミナルから変換を実行できます。CLIを使えば、1つのコマンドでVTracerエンジンの全機能を利用できるため、ベクター化をスクリプト処理の一部として組み込むことができます。

  • UIを開くことなく、1つのコマンドで変換可能
  • ビルドスクリプトやCIパイプラインにSVGエクスポートを統合
  • cronやタスクスケジューラを使って定期的なジョブをスケジュール
  • デスクトップアプリと同じ設定と出力品質

ホットフォルダの仕組み

一度設定すれば、あとはファイルをドロップするだけで自動的に変換されます。

  1. フォルダを選択: 監視するフォルダと、SVGの出力先フォルダを指定します。
  2. 画像をドロップ: PNG、JPG、BMP、WebPファイルを監視フォルダに保存またはコピーします。
  3. 即座に変換: PixelToPath Proが新しいファイルを検知し、自動的に変換します。
  4. SVGを取得: 完成したすぐに使えるベクターファイルが、出力先フォルダに用意されます。

よくある質問

画像を変換するにはPixelToPath Proが必要ですか？

いいえ。無料のデスクトップアプリでも、PNG、JPG、BMP、WebPファイルをオフラインかつ無制限にSVGへ変換できます。PixelToPath Proは、ホットフォルダ監視、一度に数百枚の画像を処理するバッチ変換、コマンドラインインターフェースといった自動化機能を追加するものです。

ホットフォルダとは具体的に何ですか？

ホットフォルダとは、PixelToPath Proが監視し続けるフォルダのことです。保存、コピー、ドロップなどによって新しい画像がそこに追加されると、アプリがそれを検知して自動的にSVGへ変換し、指定した出力先フォルダに保存します。アプリを開いたり、変換ボタンをクリックしたりする必要は一切ありません。

バッチモードでは一度に何枚の画像を変換できますか？

ライブラリ全体をキューに追加できます。100枚でも、数百枚でもインポートし、一度にすべてを変換可能です。すべての変換はVTracerエンジンを使用してローカルのCPUで実行されるため、制限はあなたのPCのスペックのみに依存します。

CLIでは何ができますか？

コマンドラインインターフェースを使用すると、グラフィカルインターフェースを開かずに、1つのコマンドで画像を変換できます。シェルスクリプト、ビルドパイプライン、CIジョブにベクター化を統合したり、cronやWindowsのタスクスケジューラを使って定期的な変換をスケジュールしたりできます。

無料版はずっと無料ですか？

はい。無料のデスクトップアプリは、MITライセンスのもとで引き続き無料、無制限、かつオープンソースとして提供されます。PixelToPath Proはプロフェッショナルなワークフロー向けのオプションのアップグレードであり、無料アプリの機能が制限されたり、使用期限が設けられたりすることはありません。

PixelToPath Proはどのオペレーティングシステムに対応していますか？

PixelToPath Proは、無料デスクトップアプリと同じプラットフォームであるWindows (64ビット) とLinuxで動作します。無料版と全く同じように、すべて完全にオフラインで機能します。

39ユーロという価格に税金は含まれていますか？

いいえ、39ユーロは税別の価格です。お住まいの国や購入手続きを行う場所に応じて、チェックアウト時にVAT(付加価値税)または売上税が加算される場合があります。

PixelToPath Proは何台のPCにインストールできますか？

Pro版のライセンスは1回限りの買い切り型(39ユーロ税別)で、永久に利用可能です。1人のユーザーを対象としており、最大3台のPC(例えば、デスクトップワークステーション、ノートPC、スタジオ用PCなど)でアクティベートできます。

画像を1枚ずつ変換するのはもうやめましょう

ホットフォルダを一度設定するだけで、あるいは100枚の未処理画像を一度の実行で片付けることができます。PixelToPath Proを使えば、ベクター化は全く意識する必要のないプロセスになります。一度の支払いで、永久にあなたのものです。
