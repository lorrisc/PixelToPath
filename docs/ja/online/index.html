PNG vs SVG、ツールの実際の出力で比較

以下はこのページのコンバーターで実際に変換した結果です。この小さな 128 px のロゴを拡大すると、PNG は正方形のピクセルに崩れるのに対し、トレースされた SVG はくっきり鮮明なままです。

PNG は画像を固定されたピクセルのグリッドとして保存するため、書き出したサイズでしか正しく表示されません。ロゴを拡大すれば輪郭がにじみ、高密度ディスプレイに表示するには同じファイルの重いバージョンを2〜3個も用意しなければなりません。一方、SVG は図形を曲線と座標で記述するため、ブラウザーは 1つの小さなファイルから、どのサイズでも鮮明に再描画できます。上の比較画像が、実際のロゴでの結果です。実務では、ロゴ・アイコン・線画・フラットなイラストは SVG に変換し、写真・スクリーンショット・テクスチャは PNG、WebP、JPG のままにしておきましょう。こうした画像では、ピクセル形式の方が実際にはよく圧縮されます。

PNG vs SVG、一目でわかる比較

同じ違いを、横並びでまとめると：

項目 PNG（ラスター） SVG（ベクター）
拡大・縮小 拡大した瞬間にぼやける 16 px から 4K まで、どのサイズでも鮮明
ファイルサイズ（ロゴ） 40〜80 KB。@2x では2倍に 2〜12 KB。全画面でファイルは 1つだけ
高密度ディスプレイ @1x、@2x、@3x の個別書き出しが必要 1つのファイルをそのまま使用
編集 つぶれたピクセル。変更には元ファイルが必要 すべての図形が編集可能なパス
最適な用途 写真、スクリーンショット、複雑な画像 ロゴ、アイコン、フラットなイラスト

1つのファイル、3つのプリセット

3つの SVG はすべて、この 512 px の PNG をこのコンバーターのプリセットで実際に変換したものです。16 px のファビコンから 4K ディスプレイまで、同じファイルがどの画面でも鮮明です。

無料画像ベクターライザー

PixelToPath は無料のオンライン画像ベクターライザーです。PNG、JPG、BMP、WebP などどんなファイルでも、クリーンで拡張可能な SVG に変換します。この技術は「ラスターからベクターへの変換」や画像トレースと呼ばれます。ピクセルごとに 1 つの色の値を保存する代わりに、エンジンが画像を数学的な曲線として組み立て直すため、ブラウザーは 16 px のファビコンから 4K ディスプレイまで、どのサイズでも完璧に再描画できます。ビットマップは拡大するたびにぼやけますが、ベクターファイルは決してぼやけません。画像をアップロードし、設定を微調整しながらライブプレビューの変化を確認したら、Illustrator、Inkscape、Figma での編集、Web サイトへの埋め込み、レーザーカッターやカッティングプロッターでの加工にそのまま使える SVG をダウンロードしましょう。

トレースモードは2種類用意されています。イラストや写真にはフルカラー、ロゴやアイコンには黒 & 白 - すべてのパラメータを調整して、よりクリーンな仕上がりにできます。

どのプリセットを使うべきですか？

PixelToPath は画像の性質に応じて3つの最適化されたプリセットを提供します。すべてのパラメータを手動で調整することも可能です。

白黒 白黒

トレース前に画像をグレースケールに変換します。単色のクリーンなパスを生成します。最適:

  • ロゴとブランドマーク
  • アイコンとピクトグラム
  • 線画とスケッチ
  • カッティングシートとレーザー彫刻

ポスター フラットカラー

高い精度で複数のカラーレイヤーが重なり合ったものとしてトレースします。最適:

  • フラットなイラストとカートゥーン
  • インフォグラフィック
  • クリップアート
  • 明確な色を持つデジタルアート

写真 写真

実際の写真の複雑さを処理するために広範なグループ化とノイズフィルタリングを使用します。最適:

  • ポートレートと顔
  • 風景写真
  • 商品写真
  • グラデーションが多い複雑な画像

よくある質問

制限なしで本当に無料ですか？

はい、完全無料です。PixelToPath はオープンソース (MIT) プロジェクトです。

カラー画像に対応していますか？

はい。VTracer を使用しています。カラーには ポスター または 写真 を選択してください。

ファイルは保存されますか？

いいえ。処理後すぐに削除されます。

サポートされているフォーマットは何ですか？

PNG、JPG、JPEG、BMP、WebP (Ctrl+V も可)。

最大ファイルサイズは？

オンラインは 20 MB まで。無制限に使用するにはデスクトップアプリをダウンロードしてください。

白黒の結果がおかしいのはなぜですか？

詳細設定で 反転 をオンにしてください。

スプライン、ポリゴン、ピクセルの違いは何ですか？

スプライン は滑らかな曲線。ポリゴン は直線。ピクセル はピクセルアート用です。

商用プロジェクトで使用できますか？

はい、ライセンス制限はありません。
