「PNG ベクター」 - その検索が実際に意味するもの

PNGをベクターに変換する方法を検索する人は、通常、次の2つの作業のいずれかを行っています。ピクセル化されたロゴを任意のサイズできれいに拡大縮小できるようにするか、印刷所、カッティングマシン、またはデザインツールが実際に受け入れるファイルを作成することです。どちらの作業も同じ場所（実際のベクターファイル）に行き着きますが、「ベクター」という言葉には2つの決定事項が隠されています。どの形式が必要か、そして変換が本物かどうかです。ファイルが今すぐ準備できている場合は、 無料のオンラインPNG-SVGコンバーターが1分未満でそれを行います。このガイドでは、そのステップに関するすべてをカバーしています。

他の何よりもまず1つの定義。真のベクターファイルは、形状を数学的なパスとして保存します - つまり、 ベクター化が実際に行うことです - そして多くのツールはそのステップを完全にスキップして偽造します。その偽物は、ズームインするか、ファイルをマシンに送信するまで目に見えません。

最大の失敗パターン：多くの「PNGベクターコンバーター」は何もトレースしません。埋め込まれたビットマップとして.svgファイル内にPNGをラップするだけです。それは依然としてピクセルの集合体であるため、結果は「完璧にスケーリング」します。出力ファイルをテキストエディタで開いてみてください。<path>要素の代わりに巨大なbase64の<image>タグが1つある場合、ベクターではなく名前が変更されたPNGを取得したことになります。このガイドのすべては、実際のトレースに関するものです。

コンバーターの実際の結果

「ベクター」の本当の意味 - そしてどの形式が必要か

PNGはラスター画像です。つまり、固定されたカラーピクセルのグリッドです。元のサイズではシャープに見えますが、拡大した瞬間に劣化します。ファイルには図形が何であるかという情報はなく、各正方形が何色であるかという情報しかないからです。ベクターグラフィックは、数学によって定義されたエッジ、カーブ、塗りつぶしなど、形状自体をパスとして保存するため、同じファイルが16ピクセルでも16メートルでも同じようにレンダリングされます。

「ベクター」はフォーマットではなく、ファミリーです。実際のベクターパスを保持するファイルタイプは4つあり、主に誰がそれを開くかによって異なります。

4つのベクターファイル形式の解説

  • SVG - Web標準。すべてのブラウザとすべてのデザインツールで開き、カッティングマシンが消費するものです。これがコンバーターが出力するものであり、このガイドが焦点を当てている形式です。
  • EPS - 従来の印刷所フォーマット。印刷ベンダーは今でも定期的にこれを要求しており、ほとんどのベクターエディターは要求に応じてエクスポートします。
  • AI - Adobe Illustratorのネイティブフォーマット。デザイナーがあなたの後にファイルを引き継ぐ場合に関連します。
  • PDF - これもベクターパスを保持しており、多くの印刷所が「印刷準備完了」ファイルを要求するときに実際に意味するものです。

PNGを無料でベクターグラフィックに変換する方法

アカウント不要、インストール不要、透かしなし。変換全体は4つの短いステップで行われます。

  1. PNGをアップロード - コンバーターにドラッグアンドドロップします。PNG、JPG、BMP、WebPはすべて同じように機能します。
  2. プリセットを選択 - ロゴや線画には「白黒」、単色のグラフィックには「ポスター」、グラデーションや陰影のある画像には「写真」。
  3. 必要に応じて微調整 - 画像ごとに、色数とパスの詳細度によってファイルサイズと忠実度のトレードオフを調整します。
  4. SVGをダウンロード - Web、印刷、またはカッティングマシン用の実際の<path>要素。

内部では、変換はオープンソースのRustトレーサーであるVTracerから派生した自動トレースエンジンを実行します。図形はラップされるのではなく、ベクターパスとして再構築されます。その一文が、これと検索結果の半分の結果との違いです。

良い変換を得るために：結果を決めるもの

トレースの品質は、ツールよりも入力に依存します。きれいなソースはほぼ完璧に変換されますが、乱雑なソースは2分間の判断を必要とします。次の3つが結果を決定します。

  • 単色 vs グラデーション - 単色のロゴは、各色の領域がきれいなベクターの形になるため、美しくトレースされます。写真は多くの小さな形にトレースされ、絵画のように見えることがあります。それが数学が実際に見ているものです。
  • プリセットの選択 - 「白黒」は画像を鮮明なシルエットに折りたたみます（ロゴやテキストに最適）。「ポスター」は限られたパレットを維持します。「写真」は、より多くのパスとより大きなファイルサイズを犠牲にしてグラデーションを保持します。
  • 詳細 vs サイズ - パスの詳細度が高いほど、忠実度が高くなり、キロバイト単位のサイズも大きくなります。ナビゲーションバーのロゴはパスが少ない方がよく、印刷ファイルは最大の忠実度が求められます。

ロゴは特に言及する価値があります。文字の形とブランドマークはまさにトレースが最も得意とするものであり、 ロゴを適切にベクター化するガイドでは、小さいサイズでもエッジを鮮明に保つための設定について説明しています。

PNGからEPSまたはAIへ：SVGをピボットフォーマットとして使用する

コンバーターは意図的にSVGを出力します。SVGは他のすべての形式が受け入れる形式だからです。印刷所がEPSを要求した場合、またはデザイナーがAIを必要とする場合のルートは次のとおりです。PNGをSVGに変換し、Inkscape（無料）またはIllustratorでSVGを開き、要求された形式に保存またはエクスポートします。パスはそのまま維持され、作業時間は1分もかかりません。ここでは意図的に直接のPNGからEPSへの変換を行っていません。1つの十分にサポートされた出力フォーマットは、3つの平凡なフォーマットに勝るからです。

逆が安全であるとは期待しないでください。ベクターをPNGにラスター化すると、ジオメトリが永遠に失われます。SVGをマスターファイルとして保持し、プロジェクトに必要な任意のサイズでPNGのコピーをエクスポートしてください。

PNGからベクターへの変換が実際に役立つ場所

すべての画像をベクターにする必要があるわけではありません。写真としてのみ表示される写真は通常、ラスターのままです。しかし、次の4つの状況では変換がすぐに役立ちます。

  • ロゴとブランドマーク - ファビコンから店頭の看板まで、あらゆるサイズの1つのファイル。二度とピクセル化することはありません。
  • 印刷作業 - 名刺、ステッカー、アパレル。印刷所はベクターを自由に拡大縮小し、背景なしでカットします。
  • カッティングマシン - Cricut、Silhouette、レーザーカッターは、ピクセルではなくベクターパスに従います。トレースされたファイルは、 Cricutまたはレーザーカットの準備ができており、あとはマシンが処理します。
  • アイコンとUIアセット - あらゆる画面密度で鮮明に表示され、多くの場合、置き換えるPNGよりもサイズが小さくなります。

共通のテーマ：画像を拡大縮小したり、カットしたり、形ごとに編集したりする必要がある場合、それはベクターである必要があります。

PNGのままにするか、ベクターにするか？ 5秒の決定

毎回同じ経験則。左の列の場合は、PNGを維持して作業をスキップします。右の列の場合は、変換します。決定するよりも時間がかかりません。

よくある質問

PNGはベクターファイルですか？

いいえ。PNGは常にラスターフォーマットです。つまり、設定された解像度を持つピクセルの固定グリッドです。PNGの名前を.svgに変更してもそれは変わりませんし、SVGラッパーに埋め込んでも変わりません。実際のベクターを取得するには、画像をトレースして、その形状をパスとして再構築する必要があります。

PNGを無料でベクターに変換するにはどうすればよいですか？

無料のオンラインコンバーターを使用します。PNGをアップロードし、プリセットを選択し、SVGをダウンロードします。アカウントは必要ありません。オフラインで作業する場合は、無料のデスクトップアプリがWindowsおよびLinuxでローカルに同じ変換を行い、無制限に単一ファイルを変換できます。

PNGを直接EPSまたはAIに変換できますか？

1つのステップではできません。また、それを主張するツールには注意してください。信頼できるルートはPNG → SVG → EPS/AIです。ここで変換し、InkscapeまたはIllustratorでSVGを開き、必要な形式にエクスポートします。ベクターパスは変更されずに通過します。

「変換された」ファイルがまだピクセル化されているのはなぜですか？

変換されたのではなく、埋め込まれたからです。一部のツールは、PNGをトレースするのではなく、base64の<image>タグとして.svgファイル内にラップします。ファイルをテキストエディターで開きます。エンコードされたデータの巨大な塊が1つあり、<path>要素がない場合は、まだPNGを見ていることになります。実際のトレースされたパスを出力するツールで再実行してください。

PNGをSVGに変換すると背景は削除されますか？

一部は仕様です。「白黒」プリセットを使用すると、トレースされた形状のみがパスになるため、平坦な背景は出力の一部にはなりません。これは、透明な背景のロゴに便利です。これは写真の被写体の切り抜きとは異なり、コンバーターはそれを行いません。「写真」プリセットはシーン全体を保持します。
