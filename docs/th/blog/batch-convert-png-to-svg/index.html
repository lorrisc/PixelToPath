วิธีแปลงไฟล์ PNG เป็น SVG แบบแบทช์ (เปรียบเทียบ 5 วิธี)

ห้าวิธีที่ผ่านการทดสอบแล้วในการแปลงไฟล์ PNG หลายไฟล์เป็น SVG ในคราวเดียว - เครื่องมือออนไลน์ โฟลเดอร์ร้อน (hot folder) แอปเดสก์ท็อปฟรี สคริปต์ และ API - เปรียบเทียบตามต้นทุน ปริมาณงาน การรองรับสี และความเป็นส่วนตัว

ปัญหาของการประมวลผลแบบแบทช์ - และหลุมพรางที่ควรหลีกเลี่ยง

คุณมี PNG สิบไฟล์ หรือสี่ร้อยไฟล์ หรือ - เหมือนกับดีไซเนอร์ที่คำถามเกี่ยวกับไฟล์ 51,000 ไฟล์ของเขาได้เริ่มกระทู้ที่ยาวที่สุดกระทู้หนึ่งบนฟอรัมชุมชน Adobe - คุณมีคลังแอสเซททั้งหมดที่ต้องถูกสร้างเป็นเวกเตอร์ การแปลงรูปภาพหนึ่งรูปด้วยตนเองนั้นทำได้ แต่ถ้าเกินจากนั้น คุณจำเป็นต้องมีเวิร์กโฟลว์การประมวลผลแบบแบทช์ (batch processing): กระบวนการเดียวที่เปลี่ยนโฟลเดอร์ภาพแรสเตอร์ทั้งโฟลเดอร์ให้กลายเป็นโฟลเดอร์ SVG และถ้าวันนี้มีเพียงไฟล์สำคัญเพียงไฟล์เดียวจริงๆ โปรแกรมแปลงไฟล์ PNG เป็น SVG ออนไลน์ฟรีก็สามารถทำงานให้เสร็จได้ในเวลาไม่ถึงนาที - คู่มือฉบับนี้ครอบคลุมทุกสิ่งที่เกินเลยจากจุดนั้น

คำนิยามหนึ่งข้อก่อนที่จะเปรียบเทียบแต่ละวิธี การแปลงแบบแบทช์ที่แท้จริงหมายความว่า PNG ทุกไฟล์จะถูก 'แปลงเป็นเวกเตอร์' (vectorized): รูปร่างของมันจะถูกวาดใหม่เป็นเส้นทางทางคณิตศาสตร์ ซึ่งนั่นคือ สิ่งที่การแปลงเป็นเวกเตอร์ทำจริงๆ เครื่องมือจำนวนมากข้ามขั้นตอนนี้ไปโดยสิ้นเชิง และมันเปลี่ยนทุกอย่างเกี่ยวกับผลลัพธ์ที่ได้

รูปแบบความล้มเหลวที่พบบ่อยที่สุด: "ตัวแปลง SVG" บางตัวไม่ได้ทำการวาดเส้น (trace) ใดๆ เลย - พวกมันแค่ห่อหุ้มไฟล์ PNG ของคุณไว้ข้างในไฟล์ .svg ในฐานะรูปภาพที่ถูกฝังไว้ (embedded image) ผลลัพธ์ที่ได้ดูเหมือนจะขยายขนาดได้ "อย่างสมบูรณ์แบบ" เพราะมันยังคงเป็นบิตแมปที่ปลอมตัวมา ลองเปิดไฟล์เอาต์พุตใดๆ ในโปรแกรมแก้ไขข้อความดูสิ: หากคุณพบแท็ก <image> แบบ base64 ขนาดใหญ่แทนที่จะเป็นองค์ประกอบ <path> นั่นหมายความว่าคุณไม่ได้แปลงอะไรเป็นเวกเตอร์เลย วิธีการด้านล่างทุกวิธีได้รับการประเมินโดยอิงจากการวาดเส้นจริง

ผลลัพธ์จริงจากตัวแปลงไฟล์

วิธีที่ 1: เครื่องมือแปลงไฟล์แบบแบทช์ออนไลน์

เส้นทางที่เร็วที่สุดสำหรับงานชุดเล็ก เครื่องมือออนไลน์เพียงหยิบมือหนึ่งที่รับหลายไฟล์พร้อมกัน: to.imagestool.com ให้คุณลากและวางชุดไฟล์ PNG และประมวลผลไฟล์เหล่านั้นในเบราว์เซอร์; Pixelied รับการอัปโหลดจำนวนมากและให้ไฟล์ ZIP ของผลลัพธ์แก่คุณ; เวอร์ชันทดลองบนเว็บของ ImageResizer.com และ reaConverter ก็ทำงานแบบเดียวกัน ไม่ต้องติดตั้ง ไม่ต้องใช้บรรทัดคำสั่ง - แค่วางไฟล์ แล้วดาวน์โหลดผลลัพธ์

มีสองสิ่งที่คุณควรตรวจสอบก่อนมอบหมายงานจริงให้เครื่องมือเหล่านี้ ประการแรก ตรวจสอบให้แน่ใจว่าเครื่องมือนั้นทำการวาดเส้นจริงๆ: เว็บไซต์ "แบบแบทช์" บางแห่งเพียงแค่วนลูปการแปลงไฟล์เดี่ยวบนเซิร์ฟเวอร์ และส่งคืนไฟล์ ZIP ของ SVG ปลอมให้คุณ - นั่นคือหลุมพรางการฝังไฟล์จากคำเตือนด้านบน ประการที่สอง หากผลงานศิลปะมีจุดประสงค์เชิงพาณิชย์หรืออยู่ภายใต้ข้อตกลง NDA ให้อ่านเงื่อนไขความเป็นส่วนตัว: เครื่องมือที่ทำงานบนเบราว์เซอร์จะไม่เคยอัปโหลดไฟล์ของคุณ แต่เครื่องมือที่ทำงานบนเซิร์ฟเวอร์จะส่งภาพแต่ละภาพไปยังคอมพิวเตอร์ของคนอื่น เพื่อความโปร่งใส: โปรแกรมแปลงไฟล์ออนไลน์ฟรีของ PixelToPath เองนั้นตั้งใจทำมาเพื่อไฟล์เดียวเท่านั้น มันเป็นเครื่องมือที่เหมาะสมสำหรับโลโก้สำคัญอันหนึ่ง ไม่ใช่สำหรับโฟลเดอร์ที่มีไฟล์สี่ร้อยไฟล์ - และสถานะของมันในการเปรียบเทียบนี้ก็อยู่ในจุดนั้นอย่างชัดเจน

วิธีที่ 2: แอปเดสก์ท็อปพร้อมโฟลเดอร์ร้อน (PixelToPath Pro)

หากการประมวลผลแบบแบทช์เป็นงานประจำทุกสัปดาห์แทนที่จะเป็นงานครั้งเดียว โฟลเดอร์ร้อน (hot folder) จะช่วยขจัดขั้นตอนแบบแมนนวลออกไปโดยสิ้นเชิง PixelToPath Pro (Windows และ Linux) จะเฝ้าดูโฟลเดอร์และแปลงรูปภาพทุกรูปที่ใส่ลงไปโดยอัตโนมัติ ขั้นตอนทั้งหมดมีเพียงสี่ขั้นตอน:

  1. เลือกโฟลเดอร์ของคุณ: เลือกโฟลเดอร์ที่จะเฝ้าดู และโฟลเดอร์เอาต์พุตที่ต้องการให้ SVG บันทึกไว้
  2. วาง PNG ของคุณ: บันทึก คัดลอก หรือลากไฟล์ทั้งหมด - ไม่ว่าจะเป็นสิบไฟล์หรือหลายร้อยไฟล์ - ลงในโฟลเดอร์อินพุต
  3. ปล่อยให้มันทำงาน: แต่ละไฟล์จะถูกวาดเส้นเมื่อมาถึงโดยใช้โปรไฟล์การตั้งค่าที่คุณบันทึกไว้ บนเครื่องคอมพิวเตอร์ของคุณทั้งหมด
  4. รวบรวม SVG: ผลลัพธ์จะปรากฏในโฟลเดอร์เอาต์พุต พร้อมกับชื่อไฟล์ต้นฉบับ

ส่วนที่สำคัญสำหรับการประมวลผลแบบแบทช์: โปรไฟล์การตั้งค่าเดียวจะถูกนำไปใช้กับคิวงานทั้งหมด หากคุณแปลงไอคอนสี่ร้อยไฟล์ด้วยตนเอง ไฟล์ที่ 300 จะไม่มีทางตรงกันอย่างสมบูรณ์แบบกับไฟล์ที่ 12; แต่ด้วยโปรไฟล์ ทุกผลลัพธ์จะมีความสอดคล้องกัน - นี่คือรายละเอียดที่มักจะทำลายเวิร์กโฟลว์แบบแมนนวล ทุกอย่างทำงานอยู่ในเครื่อง ดังนั้นจึงไม่มีการจำกัดการอัปโหลด และไฟล์จะไม่เคยออกจากคอมพิวเตอร์ของคุณ เวอร์ชัน Pro มีค่าใช้จ่ายแบบจ่ายครั้งเดียวที่ €39 (ไม่รวมภาษีมูลค่าเพิ่ม) เป็นใบอนุญาตตลอดชีพสำหรับผู้ใช้ 1 คนบนคอมพิวเตอร์สูงสุด 3 เครื่อง; หน้า การแปลงแบบแบทช์ด้วยโฟลเดอร์ร้อน ให้รายละเอียดทุกอย่างที่รวมอยู่ด้วย นี่คือหนึ่งในห้าตัวเลือกในที่นี้ - แต่มันเป็นตัวเลือกเดียวที่สร้างขึ้นมาเพื่อให้การแปลงแบบแบทช์กลายเป็นขั้นตอนที่คุณไม่ต้องนำมาคิดให้ปวดหัวอีกต่อไป

วิธีที่ 3: แอปเดสก์ท็อปฟรี และ Inkscape

ใช้แอปเดสก์ท็อปฟรีอยู่แล้วใช่ไหม? มันสามารถแปลง PNG, JPG, BMP และ WebP เป็น SVG แบบออฟไลน์ โดยไม่จำกัดจำนวนไฟล์ และให้การเข้าถึงการตั้งค่าการวาดเส้น (tracing) ขั้นสูงอย่างเต็มที่ - แต่ทำได้ทีละหนึ่งไฟล์เท่านั้น การประมวลผลแบบแบทช์คือสิ่งที่การอัปเกรดเป็นเวอร์ชัน Pro มีให้เพิ่มเติม และควรบอกสิ่งนี้ออกไปตรงๆ แทนที่จะแสร้งทำเป็นอย่างอื่น หากคุณต้องการอะไรที่ฟรี ใช้งานในเครื่อง และอิงกับ GUI (ส่วนต่อประสานกราฟิก) โปรแกรมแปลงไฟล์เดสก์ท็อปฟรี คือตัวเลือกที่ซื่อตรงที่สุดสำหรับไฟล์เดี่ยว: ปริมาณงานที่สมจริงคือหลายสิบไฟล์ต่อวัน ไม่ใช่หลายร้อย

Inkscape เป็นอีกหนึ่งเครื่องมือตัวเก่งที่ใช้งานได้ฟรี กล่องโต้ตอบ 'Trace Bitmap' ของมันก็ทำมาสำหรับภาพเดียวเช่นกัน และแม้ว่า Inkscape จะมีตัวเลือกบรรทัดคำสั่ง (command-line) ที่สามารถนำไปเขียนสคริปต์วนลูปได้ แต่ประสบการณ์ในการใช้งานก็ยากลำบากและแทบไม่มีเอกสารประกอบ โปรแกรม GIMP นั้นไม่มีฟีเจอร์ส่งออกเวกเตอร์แบบแบทช์ในตัวเลย - ซึ่งกระทู้ฟอรัมของพวกเขาก็ยืนยันเรื่องนี้เป็นประจำ ก่อนที่คุณจะเสียเวลาหลายชั่วโมงไปกับเวิร์กโฟลว์แบบ GUI โปรดตรวจสอบให้แน่ใจก่อนว่าคุณต้องการเวกเตอร์สำหรับแต่ละไฟล์จริงๆ หรือไม่: บทความเปรียบเทียบ SVG vs PNG สำหรับเว็บ ได้พูดถึงว่าเมื่อใดการแปลงรูปแบบถึงจะคุ้มค่า

วิธีที่ 4: สคริปต์บรรทัดคำสั่ง (ImageMagick, Potrace, VTracer)

สำหรับงานจำนวนมากที่ทำเพียงครั้งเดียว เชลล์สคริปต์ความยาวสิบบรรทัดก็สามารถเอาชนะ GUI ได้ทุกตัว กระบวนการสร้างภาพขาวดำสุดคลาสสิกคือการเชื่อม ImageMagick เข้ากับ Potrace - แปลงไฟล์ก่อน แล้วค่อยวาดเส้น: magick input.png input.pbm && potrace -s -o input.svg input.pbm

ห่อหุ้มคำสั่งนี้ไว้ในลูป "for" เหนือโฟลเดอร์ของคุณ แล้ว Potrace จะส่งออกเส้นทางเวกเตอร์ที่แท้จริงด้วยความเร็วของ CPU ของคุณ - แต่มันเป็นขาวดำอย่างเคร่งครัด หากต้องการให้มีสี ให้ชี้ลูปเดิมไปยัง vtracer ซึ่งเป็นโปรแกรมวาดเส้นแบบโอเพนซอร์สที่เขียนด้วยภาษา Rust และเป็นเครื่องมือที่ขับเคลื่อน PixelToPath เช่นกัน เครื่องมือทั้งสองตัวมีตัวเลือก (flags) มากพอที่จะเขียนคู่มือได้ทั้งเล่ม นั่นเป็นเหตุผลที่แต่ละตัวมีคู่มือเฉพาะกิจ (จะลิงก์ไว้ที่นี่เมื่อเผยแพร่แล้ว) สคริปต์ชนะในเรื่องของราคา (ฟรี), ความเป็นส่วนตัว (ทำในเครื่อง) และปริมาณ (หลายพันไฟล์ต่อการรัน); แต่จะแพ้ในเรื่องจุดเริ่มต้น - คุณเป็นผู้ดูแลไปป์ไลน์การทำงาน และถ้าหากวันใดระบบล่ม ก็จะไม่มีใครชดเชยเวลาที่เสียไปให้คุณ

วิธีที่ 5: วงลูป API สำหรับ CI และงานฝั่งเซิร์ฟเวอร์

เมื่อการแปลงไฟล์ต้องเกิดขึ้นบนเซิร์ฟเวอร์ - ระหว่างการนำไปปรับใช้ (deployment) ภายในไปป์ไลน์การสร้าง (build pipeline) หรือจากแบ็คเอนด์ - เครื่องมือแบบติดตั้งในเครื่องก็ไม่ใช่ตัวเลือกอีกต่อไป รูปแบบในที่นี้คือวงลูป: การใช้คำสั่ง POST แบบไม่มีสถานะหนึ่งครั้งต่อภาพ พร้อมคีย์ Bearer ของคุณ โดย SVG แต่ละไฟล์จะถูกเขียนตรงไปยังไปป์ไลน์เนื้อหา (asset pipeline) ของคุณ ขีดจำกัดคือ 60 คำขอต่อนาทีต่อคีย์ ดังนั้นคุณต้องควบคุมความเร็วของลูป และลองเรียกซ้ำสำหรับการเรียกที่ถูกจำกัดอัตราด้วยฟังก์ชัน exponential backoff; การเรียกที่ล้มเหลวจะไม่กินเครดิตของคุณ คุณสามารถ สร้างระบบอัตโนมัติแบบแบทช์ทั้งหมดด้วย REST API โดยไม่ต้องมีการติดตั้งใดๆ ในเครื่อง - ซึ่งนี่คือประเด็นสำคัญทั้งหมด

การคำนวณต้นทุนสามารถคาดการณ์ได้: รูปภาพแบบชำระเงินล่วงหน้าจะมีราคาลดลงจาก €0.05 เหลือ €0.01 ต่อชิ้นสำหรับปริมาณมาก ดังนั้น 500 รูปภาพจะมีต้นทุนประมาณ €20 และ 10,000 รูปภาพประมาณ €200 - นอกจากนี้แต่ละบัญชียังได้รับการแปลงฟรีเพิ่มเติมอีก 10 ครั้งในทุกๆ เดือน เลือกใช้ API เมื่อการแปลงนั้นต้องทำซ้ำได้ ทำอยู่ฝั่งเซิร์ฟเวอร์ และเป็นอิสระจากการพึ่งพาระบบในเครื่อง เลือกใช้โฟลเดอร์ร้อนเมื่อทำงานแบบโลคอลและมีการโต้ตอบ สองตัวเลือกนี้ครอบคลุมงานแบบแบทช์ในโลกแห่งความเป็นจริงได้เกือบทุกงาน

แบทช์ PNG เป็น SVG: เปรียบเทียบทั้งห้าวิธี

อินพุตแบบเดียวกัน กับเงื่อนไขห้าแบบที่แตกต่างกันอย่างสิ้นเชิง ต้นทุนและความเป็นส่วนตัวคือสิ่งที่เป็นโครงสร้างพื้นฐาน ไม่ใช่แค่โปรโมชัน; ปริมาณงาน (throughput) ถูกประเมินโดยสมมติว่ามีผู้ปฏิบัติงาน 1 คน (หรือเซิร์ฟเวอร์ระดับพื้นฐาน) บนฮาร์ดแวร์ที่ใช้งานได้จริง; และ "สี" ในที่นี้หมายถึงผลลัพธ์เวกเตอร์แบบหลากสีสันที่แท้จริง ไม่ใช่แค่ภาพเงาสีดำ

วิธีการ ต้นทุน ไฟล์/วัน (ความเป็นจริง) สี การควบคุมคุณภาพ ความเป็นส่วนตัว ทักษะที่ต้องการ
โปรแกรมแปลงไฟล์ออนไลน์ ฟรี 50-500 (ทำด้วยมือ) ขึ้นอยู่กับเครื่องมือ ใช้ได้เฉพาะค่าที่ตั้งไว้ล่วงหน้า แตกต่างกันไป - โปรดตรวจสอบข้อตกลง ไม่ต้องมี
โฟลเดอร์ร้อนของ Pro จ่ายครั้งเดียว €39 หลักพัน (CPU ในเครื่อง) ได้ หนึ่งโปรไฟล์ ครอบคลุมการตั้งค่าทั้งหมด โลคอล 100% ไม่ต้องมี
เดสก์ท็อปฟรี / Inkscape ฟรี 20-100 (ทีละไฟล์) ได้ (ไฟล์เดี่ยว) ปรับได้เต็มที่ สำหรับแต่ละไฟล์ โลคอล 100% พื้นฐาน
สคริปต์ (CLI) ฟรี หลายพัน+ (CPU ในเครื่อง) Potrace ไม่ได้ - VTracer ได้ ปรับได้เต็มที่ (ผ่านคำสั่ง) โลคอล บรรทัดคำสั่ง (Command line)
วงลูป API ฟรี 10 รูป/เดือน จากนั้น €0.01-0.05/รูป หลายหมื่น (60 คำขอ/นาที) ได้ กำหนดพารามิเตอร์ของเอ็นจิ้นได้ต่อการเรียกใช้ ไฟล์จะถูกอัปโหลด นักพัฒนา (Developer)

หากคุณแปลงไฟล์แบบแบทช์บ่อยกว่าเดือนละครั้ง วิธีที่ 2 และ 5 จะคืนทุนให้กับคุณภายในบ่ายวันแรกที่ใช้งานเลยทีเดียว สำหรับงานอื่นๆ ที่มีขนาดเล็กกว่านั้น วิธีที่ 1 หรือ 3 จะไม่ทำให้คุณเสียค่าใช้จ่ายอะไรเลยนอกจากเวลาเพียงเล็กน้อย

คู่มือการแปลงไฟล์ที่เกี่ยวข้อง

การแปลงแบบแบทช์เป็นเพียงขั้นตอนแรก บทความเหล่านี้จะครอบคลุมส่วนที่เหลือ

✏️ การแปลงเป็นเวกเตอร์คืออะไรกันแน่ 📈 SVG vs PNG สำหรับใช้งานบนเว็บ 🎨 นำเข้าไฟล์ SVG ของคุณไปยัง Figma หรือ Canva 🌐 โปรแกรมแปลงไฟล์ออนไลน์ฟรี

คำถามที่พบบ่อย

ฉันสามารถแปลง PNG เป็น SVG แบบแบทช์ได้ฟรีหรือไม่?

ได้ มีสองวิธี สคริปต์บรรทัดคำสั่ง (Potrace, ImageMagick, VTracer) ใช้งานได้ฟรีและไม่จำกัดจำนวนไฟล์ ส่วนแอปเดสก์ท็อปฟรีร่วมกับ Inkscape นั้นก็ฟรีเช่นกัน แต่ทำได้ทีละไฟล์เท่านั้น นอกจากนี้ยังมีเครื่องมือออนไลน์ที่รับไฟล์จำนวนมากได้ฟรี แต่ควรตรวจสอบให้แน่ใจว่าเครื่องมือเหล่านั้นทำการแปลงเป็นเวกเตอร์จริงๆ และควรอ่านเงื่อนไขความเป็นส่วนตัวก่อนที่จะส่งไฟล์ภาพงานเชิงพาณิชย์

ฉันจะรักษาสีเอาไว้ระหว่างประมวลผลแบบแบทช์ได้อย่างไร?

ใช้ตัววาดเส้นสี (color tracer) โปรแกรม Potrace จะเป็นภาพขาวดำอย่างเคร่งครัดไม่ว่าคุณจะเขียนสคริปต์อย่างไรก็ตาม; แต่ VTracer, PixelToPath Pro และ PixelToPath API จะทำงานด้วยเอนจินสีที่จะสร้างทุกพื้นที่สีใหม่ให้เป็นรูปร่างเวกเตอร์ของมันเอง คุณสามารถเขียนสคริปต์วนลูปด้วย vtracer หรือใช้รุ่น Pro หรือ API ก็ได้หากคุณไม่อยากต้องมาดูแลรักษาโค้ดเอง

ฉันสามารถอัปโหลดไฟล์ ZIP ของ PNG แล้วรับไฟล์ ZIP ของ SVG กลับมาได้ไหม?

เครื่องมือออนไลน์บางตัว (เช่น Pixelied) ยอมรับการอัปโหลดจำนวนมากและส่งไฟล์ ZIP กลับมา โหมดแบทช์ของโปรแกรมเดสก์ท็อปและสคริปต์จะบันทึกผลลัพธ์ลงในโฟลเดอร์เอาต์พุต ซึ่งคุณสามารถบีบอัดเป็นไฟล์ zip ได้ในขั้นตอนเดียว ส่วน API จะส่งคืนไฟล์ SVG หนึ่งไฟล์ต่อหนึ่งคำขอ ดังนั้นเรื่องการจัดเก็บรวบรวมไฟล์จึงเป็นหน้าที่ของคุณ - ซึ่งโดยปกติแล้วไปป์ไลน์การสร้างแอป (build pipeline) ก็ต้องการแบบนี้อยู่แล้ว

ทำไมไฟล์แบตช์ที่ฉันแปลงออกมาถึงกลายเป็นสี่เหลี่ยมสีดำ?

นั่นคือหลุมพรางของการฝังรูปภาพ: เครื่องมือเหล่านั้นนำ PNG แต่ละไฟล์ไปใส่ไว้ในโครงของ SVG แทนที่จะวาดเส้น (trace) มัน และสิ่งที่คุณเห็นก็คือภาพแรสเตอร์ที่ฝังอยู่ซึ่งแสดงผลล้มเหลว ลองเปิดไฟล์เอาต์พุตใดสักไฟล์ในโปรแกรมแก้ไขข้อความดู - ถ้าคุณเห็นแท็ก <image> แบบ base64 เพียงอันเดียวก็แสดงว่าใช่เลย ให้รันกระบวนการแบทช์นี้อีกครั้งโดยใช้เครื่องมือที่สร้างองค์ประกอบ <path> ที่แท้จริงออกมา

ฉันมีไฟล์อยู่ 50,000 ไฟล์ วิธีไหนถึงจะใช้ได้จริง?

ใช้โฟลเดอร์ร้อน (hot folder) หรือไม่ก็ API - วิธีอื่นๆ ทั้งหมดจะถึงขีดจำกัดก่อนที่จะไปถึงจำนวนนั้น ด้วยความเร็ว 60 คำขอต่อนาที API จะประมวลผลรูปภาพ 50,000 รูปได้หมดภายในเวลาจริงประมาณ 14 ชั่วโมง โดยใช้เครดิตแบบชำระเงินล่วงหน้าประมาณ €200 โฟลเดอร์ร้อนบนเครื่องของคุณทำงานแบบเดียวกันแต่อยู่ในสถานะออฟไลน์ โดยมีปริมาณงาน (throughput) ขึ้นอยู่กับ CPU ของคุณ ทั้งสองวิธีนี้รักษาการตั้งค่าให้เหมือนกันทุกประการตลอดระยะเวลาการทำงาน

พร้อมที่จะจัดการกับไฟล์ PNG กองโตของคุณหรือยัง?

แปลงไฟล์เดี่ยวด้วยเครื่องมือออนไลน์ฟรี ตั้งค่าโฟลเดอร์ร้อนในเวอร์ชัน Pro หรือใช้ API วนลูป - ทุกเส้นทางต่างก็ไปสิ้นสุดที่เส้นทางเวกเตอร์ที่สะอาดและเป็นเวกเตอร์ของแท้
