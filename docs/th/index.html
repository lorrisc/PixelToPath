แอปเดสก์ท็อป Pro

แอปเดสก์ท็อปที่ปลดล็อกทุกฟีเจอร์สำหรับงานระดับโปรดักชัน จ่ายครั้งเดียว ได้รับสิทธิ์การใช้งานตลอดชีพ

  • มีทุกฟีเจอร์ของแอปเดสก์ท็อปฟรี
  • ระบบตรวจสอบโฟลเดอร์อัตโนมัติ (Hot folder) — แปลงไฟล์ทันที
  • การแปลงไฟล์จำนวนมาก (Batch conversion) ทีละหลายร้อยภาพ
  • ใช้งานผ่าน Command-line interface (CLI) ได้เต็มรูปแบบ
  • สิทธิ์การใช้งานตลอดชีพ · 1 ผู้ใช้ · ใช้งานได้สูงสุด 3 เครื่อง

API

แปลงไฟล์เวกเตอร์จำนวนมากจากโค้ดของคุณด้วย REST เพียงครั้งเดียว: ส่งรูปภาพ รับ SVG ที่คมชัด

  • แปลงฟรี 10 ครั้งทุกเดือน
  • ใช้เอนจินเดียวกับเว็บไซต์ (Potrace + VTracer)
  • ได้ไฟล์ SVG ที่พร้อมใช้ในระดับโปรดักชัน
  • สร้างคีย์ API ได้สูงสุด 5 คีย์, กำหนดขีดจำกัด rate limits แยกแต่ละคีย์
  • แพ็กเกจเครดิตที่ไม่มีวันหมดอายุ
