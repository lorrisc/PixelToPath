การติดตาม Hot Folder

เปลี่ยนโฟลเดอร์ใดก็ได้ให้เป็นระบบแปลงไฟล์อัตโนมัติ ทันทีที่มีรูปภาพใหม่เข้ามา PixelToPath Pro จะตรวจจับและแปลงเป็น SVG ทันที - ไม่ต้องคลิก ไม่ต้องรอ ไม่ต้องเฝ้าหน้าจอ

  • แค่ลากไฟล์วาง ก็ได้ SVG ที่พร้อมใช้งานทันที
  • ตรวจจับไฟล์ใหม่และแปลงเสร็จสิ้นภายในไม่กี่วินาที
  • ไฟล์ต้นฉบับไม่ถูกแก้ไข; ไฟล์ SVG จะไปอยู่ในโฟลเดอร์ผลลัพธ์ของคุณ
  • เหมาะสำหรับไดรฟ์ที่แชร์ร่วมกัน, โฟลเดอร์ส่งออก และระบบจัดการสินทรัพย์

การแปลงไฟล์จำนวนมาก (Batch Conversion)

เลิกแปลงไฟล์ทีละรูป นำเข้าคลังภาพทั้งหมดของคุณ - ไม่ว่าจะเป็นไฟล์ PNG, JPG, BMP หรือ WebP หลักสิบหรือหลักร้อย - แล้วแปลงเป็น SVG ทั้งหมดได้ในครั้งเดียว

  • จัดคิวแปลงรูปภาพหลายร้อยไฟล์พร้อมกัน
  • ใช้การตั้งค่าเดียวกันสำหรับทุกไฟล์
  • แปลงชุดไอคอนทั้งหมดได้ในคลิกเดียว
  • แสดงความคืบหน้าและผลลัพธ์ในมุมมองที่ชัดเจน

ส่วนติดต่อผ่านบรรทัดคำสั่ง (CLI)

สั่งแปลงไฟล์จากเทอร์มินัลของคุณ CLI มอบพลังทั้งหมดของเอนจิน VTracer ภายในคำสั่งเดียว ทำให้การแปลงเวกเตอร์เป็นเพียงอีกขั้นตอนหนึ่งในสคริปต์ของคุณ

  • แปลงไฟล์ด้วยคำสั่งเดียว ไม่ต้องพึ่งพาหน้าจอผู้ใช้งาน
  • ผนวกรวมการส่งออก SVG เข้ากับสคริปต์การสร้าง (build scripts) และ CI pipeline
  • ตั้งเวลาทำงานประจำด้วย cron หรือ Task Scheduler
  • ตั้งค่าและได้คุณภาพผลลัพธ์แบบเดียวกับแอปเดสก์ท็อป

Hot Folder ทำงานอย่างไร

ตั้งค่าเพียงครั้งเดียวแล้วปล่อยให้ทำงาน - ทุกไฟล์ที่คุณลากวางจะถูกแปลงโดยอัตโนมัติ

  1. เลือกโฟลเดอร์ของคุณ: เลือกโฟลเดอร์ที่ต้องการติดตามและโฟลเดอร์ปลายทางสำหรับไฟล์ SVG
  2. วางรูปภาพ: บันทึกหรือคัดลอกไฟล์ PNG, JPG, BMP หรือ WebP ใดๆ ลงในโฟลเดอร์ที่ติดตาม
  3. แปลงไฟล์ทันที: PixelToPath Pro จะตรวจพบไฟล์ใหม่และทำการแปลงโดยอัตโนมัติ
  4. รับไฟล์ SVG: ไฟล์เวกเตอร์ที่เสร็จสมบูรณ์และพร้อมใช้งานจะรอคุณอยู่ในโฟลเดอร์ผลลัพธ์

คำถามที่พบบ่อย (FAQ)

จำเป็นต้องใช้ PixelToPath Pro เพื่อแปลงรูปภาพหรือไม่?

ไม่จำเป็น แอปเดสก์ท็อปฟรีสามารถแปลงไฟล์ PNG, JPG, BMP และ WebP เป็น SVG แบบออฟไลน์และไม่จำกัดจำนวนอยู่แล้ว PixelToPath Pro จะเพิ่มระบบอัตโนมัติเข้าไป: การติดตาม Hot Folder, แปลงรูปภาพหลายร้อยไฟล์พร้อมกัน, และส่วนติดต่อผ่านบรรทัดคำสั่ง (CLI)

Hot Folder คืออะไร?

Hot Folder คือโฟลเดอร์ที่ PixelToPath Pro คอยเฝ้าติดตามอยู่เสมอ เมื่อใดก็ตามที่มีรูปภาพใหม่ปรากฏขึ้น - ไม่ว่าคุณจะบันทึก คัดลอก หรือลากไฟล์มาวาง - แอปจะตรวจพบและแปลงเป็น SVG โดยอัตโนมัติ จากนั้นจะนำผลลัพธ์ไปไว้ในโฟลเดอร์ที่คุณกำหนดไว้ คุณไม่ต้องเปิดแอปหรือคลิกแปลงไฟล์เลย

โหมดแปลงไฟล์จำนวนมาก (Batch) รองรับการแปลงพร้อมกันกี่ไฟล์?

คุณสามารถจัดคิวคลังภาพทั้งหมดของคุณ - จะนำเข้า 100 รูป หรือหลายร้อยรูป - และแปลงไฟล์ทั้งหมดได้ในรวดเดียว ข้อจำกัดเพียงอย่างเดียวคือสเปคเครื่องของคุณ เพราะการแปลงไฟล์แต่ละครั้งจะทำงานบน CPU ในเครื่องด้วยเอนจิน VTracer

ฉันสามารถทำอะไรกับ CLI ได้บ้าง?

ส่วนติดต่อผ่านบรรทัดคำสั่ง (CLI) ช่วยให้คุณแปลงรูปภาพด้วยคำสั่งเดียวโดยไม่ต้องเปิดหน้าต่างโปรแกรม คุณสามารถผนวกรวมการแปลงเวกเตอร์เข้ากับเชลล์สคริปต์, build pipeline และระบบ CI หรือตั้งเวลาแปลงไฟล์เป็นประจำผ่านเครื่องมืออย่าง cron หรือ Windows Task Scheduler ได้

เวอร์ชันฟรีจะยังคงฟรีต่อไปหรือไม่?

ใช่ แอปเดสก์ท็อปฟรีจะยังคงใช้งานได้ฟรี ไม่จำกัด และเป็นโอเพนซอร์สภายใต้สิทธิบัตร MIT เสมอ PixelToPath Pro เป็นเพียงตัวเลือกอัปเกรดสำหรับระบบงานระดับมืออาชีพ - แอปฟรีไม่ได้ถูกลดทอนฟีเจอร์หรือจำกัดเวลาการใช้งานใดๆ

PixelToPath Pro รองรับระบบปฏิบัติการใดบ้าง?

PixelToPath Pro รองรับการทำงานบน Windows (64-bit) และ Linux ซึ่งเป็นแพลตฟอร์มเดียวกับแอปเดสก์ท็อปฟรี ทุกอย่างทำงานแบบออฟไลน์ 100% เช่นเดียวกับเวอร์ชันฟรี

ราคา €39 รวมภาษีแล้วหรือยัง?

ยังไม่รวม - €39 เป็นราคาที่ไม่รวมภาษีมูลค่าเพิ่ม (VAT) ระบบอาจเรียกเก็บ VAT หรือภาษีการขายเพิ่มเติมในขั้นตอนชำระเงิน ขึ้นอยู่กับประเทศและสถานที่ที่คุณทำรายการ

สามารถติดตั้ง PixelToPath Pro ได้กี่เครื่อง?

ลิขสิทธิ์รุ่น Pro เป็นการซื้อขาดในครั้งเดียว: ราคา €39 ไม่รวม VAT, ใช้งานได้ตลอดชีพ สิทธิ์นี้ครอบคลุมการใช้งานสำหรับ 1 ผู้ใช้ และสามารถเปิดใช้งานได้สูงสุด 3 เครื่อง - ตัวอย่างเช่น เวิร์กสเตชันตั้งโต๊ะ, แล็ปท็อป, และคอมพิวเตอร์ในสตูดิโอ
