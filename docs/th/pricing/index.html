€39จ่ายครั้งเดียว

สำหรับงานระดับโปรดักชัน: ระบบอัตโนมัติและการแปลงไฟล์จำนวนมาก ปลดล็อกการใช้งานตลอดชีพ

  • มีทุกฟีเจอร์ของแอปเดสก์ท็อปฟรี
  • ตรวจสอบโฟลเดอร์อัตโนมัติ (Hot folder) — แปลงไฟล์ทันที
  • แปลงไฟล์จำนวนมากเป็นร้อยๆ ภาพได้พร้อมกัน (Batch conversion)
  • ใช้งานผ่าน Command-line interface (CLI) ได้เต็มรูปแบบ
  • สิทธิ์การใช้งานตลอดชีพ · 1 ผู้ใช้ · ใช้งานได้สูงสุด 3 เครื่อง

สิ่งที่คุณไม่ต้องจ่าย

ราคาทุกรายการบนหน้านี้คือราคาสุทธิ สิ่งที่จะไม่ปรากฏในใบเรียกเก็บเงินของคุณอย่างแน่นอน:

  • ไม่มีการเรียกเก็บเงินซ้ำ — เครื่องมือออนไลน์และแอปเดสก์ท็อปใช้งานได้ฟรีตลอดไป, Pro เป็นการจ่ายเพียงครั้งเดียว (one-time payment) และ API ทำงานด้วยระบบเครดิตเติมเงินที่ไม่มีวันหมดอายุ
  • ไม่จำเป็นต้องมีบัญชีหรือบัตรเครดิตในการเริ่มต้น — สามารถแปลงไฟล์บนเบราว์เซอร์ได้โดยไม่ต้องลงทะเบียน และแพ็กเกจ API ฟรีจะขอเพียงแค่อีเมลเท่านั้น
  • ไม่มีลายน้ำ ในทุกกรณี — ไฟล์ SVG ที่คุณดาวน์โหลดจะมีลักษณะเหมือนกันทุกประการ ไม่ว่าจะมาจากเวอร์ชันฟรีหรือแบบชำระเงิน
  • ไม่มีค่าใช้จ่ายแอบแฝง — มีการคำนวณภาษีมูลค่าเพิ่ม (VAT) อัตโนมัติเมื่อชำระเงิน และเครดิต API ที่ยังไม่ได้ใช้จะถูกเก็บไว้จนกว่าคุณจะต้องการใช้งาน

คำถามที่พบบ่อยเกี่ยวกับราคา

ตัวแปลงไฟล์ออนไลน์ใช้งานได้ฟรีจริงๆ หรือ?

ใช่ เครื่องมือออนไลน์ใช้งานได้ไม่จำกัดและไม่จำเป็นต้องมีบัญชี โดยใช้เอนจินเดียวกันกับเวอร์ชันอื่นทั้งหมด — คำว่าฟรีหมายถึงฟรีจริงๆ และไม่มีการใส่ลายน้ำลงในผลลัพธ์

ใบอนุญาตแบบ Pro เป็นการสมัครสมาชิกรายเดือนหรือไม่?

ไม่ใช่ แอปเดสก์ท็อป Pro เป็นการจ่ายเงินเพียงครั้งเดียว (one-time payment) ในราคา €39 (ไม่รวม VAT) สำหรับสิทธิ์การใช้งานตลอดชีพ: 1 ผู้ใช้, ติดตั้งได้สูงสุด 3 เครื่อง ไม่มีการเรียกเก็บเงินรายเดือนหรือรายปีใดๆ

เครดิต API มีวันหมดอายุหรือไม่?

ไม่มี เครดิตที่คุณซื้อจะยังคงอยู่ในบัญชีของคุณจนกว่าคุณจะใช้งาน นอกจากนี้ทุกบัญชียังได้รับสิทธิ์แปลงไฟล์ฟรี 10 ครั้งในทุกๆ เดือน ซึ่งจะถูกใช้งานก่อนเครดิตที่คุณซื้อมาเสมอ

ระบบการชำระเงินทำงานอย่างไร?

การชำระเงินทั้งหมดดำเนินการผ่าน Lemon Squeezy ในฐานะผู้ขายสินค้า (merchant of record) คุณสามารถชำระผ่านบัตรเครดิต, Apple Pay หรือ PayPal โดยระบบจะคำนวณภาษีมูลค่าเพิ่ม (VAT) หรือภาษีการขายให้อัตโนมัติ และส่งใบแจ้งหนี้ให้คุณทางอีเมล

ฉันสามารถอัปเกรดในภายหลังได้หรือไม่?

ได้ตลอดเวลา เวอร์ชันฟรีไม่มีการจำกัดระยะเวลาการใช้งาน และคุณสามารถเพิ่มสิทธิ์การใช้งาน Pro หรือซื้อเครดิต API ได้ทุกเมื่อที่คุณต้องการ โดยทั้งหมดจะยังคงใช้เอนจินการแปลงไฟล์ตัวเดียวกัน

เริ่มใช้งานฟรีตั้งแต่วันนี้

ทุกเวอร์ชันสามารถเริ่มต้นใช้งานได้ฟรี เลือกเวอร์ชันที่คุณต้องการและแปลงภาพแรกของคุณภายในไม่กี่วินาที
