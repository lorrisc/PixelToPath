Ce que vous ne payez pas

Chaque prix sur cette page est le prix final. Ce qui n'apparaîtra jamais sur votre facture :

  • Aucun abonnement récurrent — l'outil en ligne et l'application de bureau sont gratuits à vie, Pro est un paiement unique, et l'API fonctionne sur des crédits prépayés qui n'expirent jamais.
  • Pas de compte ou de carte bancaire pour commencer — convertissez dans le navigateur sans vous inscrire, et le plan gratuit de l'API ne demande qu'une adresse e-mail.
  • Jamais de filigranes — le SVG que vous téléchargez est identique qu'il provienne d'une version gratuite ou payante.
  • Pas de frais surprises — la TVA est calculée automatiquement lors du paiement, et les crédits API inutilisés attendent simplement que vous en ayez besoin.

FAQ Tarification

Le convertisseur en ligne est-il vraiment gratuit ?

Oui. L'outil en ligne est illimité et ne nécessite aucun compte. Il s'agit du même moteur que pour les autres versions — gratuit signifie gratuit, sans aucun filigrane sur le résultat.

La licence Pro est-elle un abonnement ?

Non. L'App de bureau Pro est un paiement unique de 39 € (hors TVA) pour une licence à vie : 1 utilisateur, utilisable sur jusqu'à 3 machines. Il n'y a pas de frais récurrents.

Les crédits API expirent-ils ?

Non. Les crédits achetés restent sur votre compte jusqu'à ce que vous les utilisiez. Chaque compte bénéficie également de 10 conversions gratuites chaque mois, consommées avant les crédits.

Comment sont gérés les paiements ?

Tous les paiements passent par Lemon Squeezy en tant que marchand officiel : carte bancaire, Apple Pay ou PayPal. La TVA ou la taxe de vente est calculée automatiquement et une facture vous est envoyée par e-mail.

Puis-je passer à la version supérieure plus tard ?

À tout moment. Les versions gratuites n'ont pas de limite de temps, et la version Pro ou des crédits API peuvent être ajoutés quand vos besoins augmentent — ils utilisent tous le même moteur de conversion.
