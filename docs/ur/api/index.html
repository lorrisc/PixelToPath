API

PixelToPath API

ایک REST کال کے ساتھ تصاویر کو پروگرامیٹک طور پر ویکٹرائز کریں۔ PNG، JPG، BMP یا WebP فائل اپ لوڈ کریں، اور ایک صاف، پروڈکشن کے لیے تیار SVG واپس حاصل کریں۔ بلیک اینڈ وائٹ لائن آرٹ کو Potrace ٹریس کرتا ہے، رنگین تصاویر کو VTracer — وہی انجن جو مفت آن لائن کنورٹر میں استعمال ہوتے ہیں۔

اپنی API کلید حاصل کریں پورٹل میں سائن ان کریں دستاویزات پڑھیں ↓

فوری شروعات

تین اقدامات اور آپ اپنے ٹرمینل، اسکرپٹس یا اپنی ایپ سے تصاویر کو SVG میں تبدیل کر رہے ہوں گے۔

1 · اپنا اکاؤنٹ بنائیں

کلائنٹ پورٹل پر اپنے ای میل اور پاس ورڈ (10+ حروف) کے ساتھ رجسٹر کریں۔ کریڈٹ کارڈ کی ضرورت نہیں ہے۔

2 · API کلید بنائیں

پورٹل میں، ایک کلید بنائیں۔ یہ ایک بار دکھائی جاتی ہے — اسے محفوظ طریقے سے اسٹور کریں۔ کلیدیں ptp_live_… جیسی نظر آتی ہیں اور انہیں کسی بھی وقت منسوخ کیا جا سکتا ہے۔

3 · /v1/convert پر کال کریں

Authorization ہیڈر میں اپنی کلید کے ساتھ ملٹی پارٹ/فارم-ڈیٹا (multipart/form-data) کے طور پر اپنی تصویر بھیجیں۔ SVG ریسپانس باڈی میں واپس آتا ہے۔

آپ کی پہلی کنورژن

curl -sS -f -X POST https://api.pixel-to-path.com/v1/convert \
  -H "Authorization: Bearer ptp_live_YOUR_KEY" \
  -F "file=@logo.png" \
  -F "colormode=binary" \
  -o logo.svg

انٹرایکٹو حوالہ: pixel-to-path.com/v1/docs (OpenAPI/Swagger).

تصدیق (Authentication)

ہر درخواست کی تصدیق Authorization ہیڈر میں ایک Bearer ٹوکن کے ساتھ کی جاتی ہے:

Authorization: Bearer ptp_live_0123abc…
  • کلیدیں خفیہ ہوتی ہیں: انہیں سرور سائیڈ پر ہیش کر کے محفوظ کیا جاتا ہے اور تخلیق کے وقت صرف ایک بار دکھایا جاتا ہے۔ کلید کھو گئی؟ اسے منسوخ کریں اور ایک نئی بنائیں۔
  • ایک اکاؤنٹ، متعدد کلیدیں: اپنے پروجیکٹس کو الگ کرنے کے لیے 5 تک فعال کلیدیں بنائیں۔ آپ کا ماہانہ مفت کوٹہ اکاؤنٹ کے لحاظ سے شمار کیا جاتا ہے، کلید کے لحاظ سے نہیں۔
  • فوری منسوخی: منسوخ کی گئی کلید فوری طور پر کام کرنا بند کر دیتی ہے، چاہے پورٹل سے ہو یا بین (ban) شدہ اکاؤنٹ کے API ریسپانس سے۔

POST /v1/convert

ایک ہی اسٹیٹ لیس (stateless) کال میں اپ لوڈ + کنورژن۔ ایک کامیاب کال پر زیادہ سے زیادہ 1 کریڈٹ خرچ ہوتا ہے — ناکام، غلط یا ریٹ لمٹ شدہ کالز پر کچھ خرچ نہیں ہوتا۔

درخواست (multipart/form-data)

فیلڈ قسم پہلے سے طے شدہ تفصیل
file file — تبدیل کی جانے والی تصویر۔ PNG, JPEG, BMP یا WebP · زیادہ سے زیادہ 20 MB · زیادہ سے زیادہ 50 Mpx · کم از کم 64×64 px۔
colormode string color <code>color</code> VTracer انجن کا استعمال کرتا ہے، <code>binary</code> Potrace (بلیک اینڈ وائٹ) کا استعمال کرتا ہے۔
mode string spline صرف کلر (VTracer) — بائنری موڈ میں نظر انداز کیا جاتا ہے۔ spline | polygon | none
hierarchical string stacked صرف کلر (VTracer) — بائنری موڈ میں نظر انداز کیا جاتا ہے۔ stacked | cutout
filter_speckle int 4 صرف کلر (VTracer) — بائنری موڈ میں نظر انداز کیا جاتا ہے۔ 0–16 — چھوٹے شور کے دھبے ہٹاتا ہے۔
color_precision int 6 صرف کلر (VTracer) — بائنری موڈ میں نظر انداز کیا جاتا ہے۔ 1–8 — ہر رنگ چینل میں اہم بٹس کی تعداد۔
layer_difference int 16 صرف کلر (VTracer) — بائنری موڈ میں نظر انداز کیا جاتا ہے۔ 0–64 — رنگ کی تہوں کے درمیان فاصلہ۔
corner_threshold int 60 0–180 — کونوں کی شناخت کا زاویہ (دونوں انجن)۔
length_threshold float 4.0 3.5–10 — سیگمنٹ کی کم از کم لمبائی (دونوں انجن)۔
splice_threshold int 45 0–180 — راستے کی تقسیم کا زاویہ (دونوں انجن)۔
path_precision int 3 0–8 — راستے کے کوآرڈینیٹس میں اعشاریہ ہندسے۔
invert bool false صرف بائنری (Potrace) — کلر موڈ میں نظر انداز کیا جاتا ہے۔ تاریک حصوں کی بجائے روشن حصوں کو ٹریس کریں۔
turdsize int 2 صرف بائنری (Potrace) — کلر موڈ میں نظر انداز کیا جاتا ہے۔ 0–20 — اس سائز تک کے دھبے دباتا ہے۔
alphamax float 1.0 صرف بائنری (Potrace) — کلر موڈ میں نظر انداز کیا جاتا ہے۔ 0–1.334 — کونوں کی ہمواری کی حد۔
opttolerance float 0.2 صرف بائنری (Potrace) — کلر موڈ میں نظر انداز کیا جاتا ہے۔ 0–10 — وکر بہتری کی رواداری۔

"colormode" کے ذریعے منتخب کردہ دو انجن

API بالکل وہی انجن چلاتی ہے جو مفت آن لائن کنورٹر اور ڈیسک ٹاپ ایپ میں ہیں:

بائنری — Potrace

لائن آرٹ، اسکینز، اسکیچز اور لوگوز کی بلیک اینڈ وائٹ ٹریسنگ۔ تصویر کے تاریک حصے (گریسکیل < 50%) کو سفید پس منظر پر ٹریس کیا جاتا ہے۔ turdsize (شور ہٹانا)، alphamax (کونوں کو ہموار کرنا) اور opttolerance (پاتھ آپٹیمائزیشن) کے ساتھ آؤٹ پٹ کو فائن ٹیون کریں۔

کلر — VTracer

تصاویر، کارٹونز اور خاکوں کے لیے لیئرڈ کلر ویکٹرائزیشن۔ filter_speckle، color_precision، layer_difference کے ساتھ تفصیل کی سطح کو اور mode (اسپلائن، پولی گون، کوئی نہیں) کے ساتھ کرو فٹنگ (curve fitting) کو کنٹرول کریں۔

تصاویر کو بالکل ویب سائٹ کی طرح پری پروسیس کیا جاتا ہے: تبادلوں سے پہلے سب سے لمبی سائیڈ کو 1500 px میں تبدیل کر دیا جاتا ہے، اور API X-Detected-Type ہیڈر میں تصویر کی شناخت شدہ قسم (line_art، logo، photo یا illustration) واپس کرتا ہے۔

ریسپانس

کامیابی پر: image/svg+xml کے ساتھ 200 OK — باڈی بذات خود SVG فائل ہے۔ معلوماتی ہیڈرز:

ہیڈر تفصیل
X-Credits-Remainingاس کال کے ڈیبٹ کے بعد، اکاؤنٹ پر باقی بچنے والے ادا شدہ کریڈٹس۔
X-Free-Remainingاس ماہ باقی بچنے والے مفت تبادلے۔
X-Detected-Typeتصویر کی شناخت شدہ قسم (معلومات): line_art, logo, photo یا illustration۔
X-Processing-Timeسرور پروسیسنگ کا وقت سیکنڈز میں۔

اسے کال کرنے کے لیے استعمال ہونے والی کلید کے لیے اکاؤنٹ کی حیثیت۔ مفت — یہ کبھی آپ کے کوٹے کے خلاف شمار نہیں ہوتا، کبھی ڈیبٹ نہیں ہوتا۔

غلطیاں (Errors)

ہر غلطی ایک مستقل JSON لفافہ (envelope) واپس کرتی ہے۔ ناکام کالز پر کبھی کریڈٹ خرچ نہیں ہوتا۔

HTTP/1.1 402 Payment Required
{
  "error": {
    "code": "quota_exceeded",
    "message": "Monthly free quota used and no credits left.",
    "usage": { "free_used": 10, "free_limit": 10, "credits": 0 }
  }
}
HTTP کوڈ کب
401invalid_api_keyغائب، غلط شکل والی، نامعلوم یا منسوخ شدہ API کلید۔
402quota_exceededماہانہ مفت کوٹہ استعمال ہو گیا اور کوئی کریڈٹ باقی نہیں بچا۔
403account_bannedاکاؤنٹ پر پابندی ہے — اس کی تمام کلیدیں مسترد کر دی گئی ہیں۔
403ip_blockedکالر کا IP بلاک لسٹ میں ہے۔
413file_too_largeفائل 20 MB سے بڑی ہے۔
422invalid_image / image_too_small / invalid_paramsغلط تصویر، تصویر بہت چھوٹی ہے یا پیرامیٹر کی قدر غلط ہے۔
429rate_limitedفی کلید شرح کی حد سے تجاوز (نیچے دیکھیں)۔ اس میں ایک Retry-After ہیڈر شامل ہے۔
500internal_errorسرور سائیڈ پر تبدیلی ناکام ہو گئی — کوئی کریڈٹ چارج نہیں کیا جاتا۔

Python

import requests

resp = requests.post(
    "https://api.pixel-to-path.com/v1/convert",
    headers={"Authorization": "Bearer ptp_live_YOUR_KEY"},
    files={"file": open("photo.jpg", "rb")},
    data={"colormode": "color", "filter_speckle": 4},
)
resp.raise_for_status()
print(resp.headers["X-Credits-Remaining"], "credits left")
with open("photo.svg", "wb") as f:
    f.write(resp.content)

عمومی سوالات (FAQ)

ایک کنورژن کسے شمار کیا جاتا ہے؟

ایک کامیاب POST /v1/convert کال جو SVG واپس کرتی ہے۔ ناکام کالز (غلط تصویر، غلط پیرامیٹرز، ریٹ لمٹ، سرور ایرر) اور GET /v1/me کالز پر کبھی چارج نہیں کیا جاتا۔

ماہانہ مفت کوٹہ کیسے شمار کیا جاتا ہے؟

اکاؤنٹ کے لحاظ سے، UTC کیلنڈر مہینے پر — یہ پہلی تاریخ کو 00:00 UTC پر ری سیٹ ہوتا ہے۔ متعدد API کلیدیں بنانے سے مفت کوٹہ ضرب نہیں کھاتا: ایک اکاؤنٹ کی تمام کلیدیں انہی 10 مفت تبادلوں کا اشتراک کرتی ہیں۔

کیا کریڈٹس کی میعاد ختم ہوتی ہے؟

نہیں، خریدے گئے کریڈٹس آپ کے اکاؤنٹ پر اس وقت تک رہتے ہیں جب تک آپ انہیں استعمال نہیں کرتے۔ وہ آپ کے 10 مفت ماہانہ تبادلوں کے ختم ہونے کے بعد ہی استعمال ہوتے ہیں۔

میں ایک مہینے میں مزید تبادلے کیسے حاصل کروں؟
