PNG بمقابلہ SVG: کیا فرق ہے؟

PNG فائل کیا ہے؟

PNG (پورٹ ایبل نیٹ ورک گرافکس) ایک راسٹر امیج فارمیٹ ہے۔ یہ پکسلز کے ایک فکسڈ گرڈ کے طور پر تصاویر کو اسٹور کرتا ہے۔ جب آپ کسی PNG کو زوم ان کرتے ہیں یا بڑے فارمیٹ میں پرنٹ کرتے ہیں، تو آپ دیکھیں گے کہ تصویر دھندلی یا پکسلیٹڈ ہو جاتی ہے۔ PNG فائلیں تصاویر، اسکرین شاٹس، اور فکسڈ سائز کے ویب گرافکس کے لیے بہترین ہیں - لیکن یہ اسکیل ایبل نہیں ہوتیں۔

SVG فائل کیا ہے؟

SVG (اسکیل ایبل ویکٹر گرافکس) ایک ویکٹر امیج فارمیٹ ہے۔ پکسلز کے بجائے، یہ ریاضیاتی پاتھز اور نقاط (coordinates) کا استعمال کرتے ہوئے شکلوں کو بیان کرتا ہے۔ ایک SVG لوگو کو 10px یا 10 میٹر تک بے عیب وضاحت کے ساتھ دکھایا جا سکتا ہے۔ SVG فائلیں سائز میں بھی چھوٹی ہوتی ہیں، کوڈ میں قابلِ ترمیم ہوتی ہیں، اور CSS کے ساتھ اسٹائل کی جا سکتی ہیں - جو انہیں لوگوز، آئیکنز، اور تمثیلوں (illustrations) کے لیے مثالی بناتی ہیں۔

ویکٹرائزیشن (راسٹر سے ویکٹر) کیا ہے؟

ویکٹرائزیشن ایک راسٹر امیج (جیسے PNG) کو ویکٹر فائل (جیسے SVG) میں تبدیل کرنے کا عمل ہے۔ PixelToPath آپ کی تصویر کی شکلوں اور رنگوں کو ٹریس کرنے اور ہموار، اسکیل ایبل SVG پاتھز بنانے کے لیے VTracer انجن کا استعمال کرتا ہے۔ یہ اس وقت ضروری ہے جب آپ کو معیار کھوئے بغیر لوگو کا سائز تبدیل کرنے کی ضرورت ہو، یا لیزر کٹر یا اسکرین پرنٹنگ کے لیے آرٹ ورک تیار کرنا ہو۔
