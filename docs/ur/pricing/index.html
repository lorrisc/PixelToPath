جس چیز کی آپ ادائیگی نہیں کرتے

اس صفحے پر موجود ہر قیمت مکمل قیمت ہے۔ جو آپ کے بل پر کبھی نہیں آتا:

  • کوئی بار بار آنے والا خرچ نہیں — آن لائن ٹول اور ڈیسک ٹاپ ایپ ہمیشہ کے لیے مفت ہیں، Pro ایک بار کی ادائیگی ہے، اور API پری پیڈ کریڈٹس پر چلتا ہے جن کی میعاد کبھی ختم نہیں ہوتی۔
  • شروع کرنے کے لیے کسی اکاؤنٹ یا کریڈٹ کارڈ کی ضرورت نہیں — سائن اپ کیے بغیر براؤزر میں تبدیل کریں، اور API کا مفت ٹائر صرف ایک ای میل طلب کرتا ہے۔
  • کوئی واٹر مارکس نہیں، کبھی بھی — آپ جو SVG ڈاؤن لوڈ کرتے ہیں وہ یکساں ہوتا ہے چاہے وہ مفت ورژن سے آئے یا ادا شدہ سے۔
  • کوئی حیران کن چارجز نہیں — چیک آؤٹ پر VAT/ٹیکس کا خود بخود حساب لگایا جاتا ہے، اور غیر استعمال شدہ API کریڈٹس صرف اس وقت تک انتظار کرتے ہیں جب تک آپ کو ان کی ضرورت نہ ہو۔

قیمتوں کے حوالے سے عمومی سوالات (FAQ)

کیا آن لائن کنورٹر واقعی مفت ہے؟

جی ہاں۔ آن لائن ٹول لامحدود ہے اور اس کے لیے کسی اکاؤنٹ کی ضرورت نہیں ہے۔ یہ ہر دوسرے ورژن کی طرح ایک ہی انجن ہے — مفت کا مطلب مفت ہے، آؤٹ پٹ پر بغیر کسی واٹر مارک کے۔

کیا پرو لائسنس ایک سبسکرپشن ہے؟

نہیں۔ ڈیسک ٹاپ ایپ پرو لائف ٹائم لائسنس کے لیے €39 (VAT کے علاوہ) کی ایک بار کی ادائیگی ہے: 1 صارف، جو 3 مشینوں تک استعمال کے قابل ہے۔ کوئی بار بار چارج نہیں ہے۔

کیا API کریڈٹس کی میعاد ختم ہو جاتی ہے؟

نہیں۔ خریدے گئے کریڈٹس آپ کے اکاؤنٹ پر اس وقت تک رہتے ہیں جب تک آپ انہیں استعمال نہیں کرتے۔ ہر اکاؤنٹ کو ہر ماہ 10 مفت تبادلے بھی ملتے ہیں، جو کریڈٹس سے پہلے استعمال ہوتے ہیں۔

ادائیگیاں کیسے سنبھالی جاتی ہیں؟

تمام ادائیگیاں مرچنٹ آف ریکارڈ (merchant of record) کے طور پر Lemon Squeezy کے ذریعے ہوتی ہیں: کارڈ، Apple Pay یا PayPal، VAT/سیلز ٹیکس کا خود بخود حساب لگایا جاتا ہے، اور ایک انوائس ای میل کے ذریعے بھیجی جاتی ہے۔

کیا میں بعد میں اپ گریڈ کر سکتا ہوں؟

کسی بھی وقت۔ مفت ورژنز کی کوئی وقت کی حد نہیں ہے، اور جب آپ کی ضروریات بڑھ جائیں تو پرو یا API کریڈٹس شامل کیے جا سکتے ہیں — یہ سب ایک ہی کنورژن انجن استعمال کرتے ہیں۔
