التسعير

أداة واحدة، بأربع طرق للاستخدام

نفس محرك التحويل القوي في كل مكان — اختر الإصدار الذي يناسب سير عملك. ابدأ مجانًا، وقم بالترقية فقط إذا كنت بحاجة إلى المزيد.

الإصدارات والأسعار

لا توجد اشتراكات باستثناء المكان الذي تختار فيه الأرصدة. لا توجد رسوم خفية. يتم التعامل مع ضريبة القيمة المضافة تلقائيًا عند الدفع.

ما لا تدفع ثمنه

كل سعر في هذه الصفحة هو السعر الإجمالي. ما لا يظهر أبدًا في فاتورتك:

  • لا يوجد شيء متكرر — الأداة عبر الإنترنت وتطبيق سطح المكتب مجانيان إلى الأبد، و Pro هو دفعة لمرة واحدة، وتعمل API على أرصدة مسبقة الدفع لا تنتهي صلاحيتها أبدًا.
  • لا يوجد حساب أو بطاقة ائتمان للبدء — قم بالتحويل في المتصفح دون تسجيل، ولا تطلب الباقة المجانية لـ API سوى بريد إلكتروني.
  • بدون علامات مائية، أبدًا — ملف SVG الذي تقوم بتنزيله مطابق سواء كان قادمًا من إصدار مجاني أو مدفوع.
  • لا توجد رسوم مفاجئة — يتم حساب ضريبة القيمة المضافة تلقائيًا عند الدفع، وتظل أرصدة API غير المستخدمة ببساطة في انتظارك حتى تحتاج إليها.

الأسئلة الشائعة حول التسعير

هل المحول عبر الإنترنت مجاني حقًا؟

نعم. الأداة عبر الإنترنت غير محدودة ولا تتطلب أي حساب. إنه نفس المحرك الموجود في كل إصدار آخر — مجاني يعني مجاني، ولا توجد علامة مائية على المخرجات.

هل ترخيص Pro هو اشتراك؟

لا. تطبيق سطح المكتب Pro عبارة عن دفعة لمرة واحدة بقيمة 39 يورو (باستثناء ضريبة القيمة المضافة) للحصول على ترخيص مدى الحياة: مستخدم واحد، قابل للاستخدام على ما يصل إلى 3 أجهزة. لا توجد رسوم متكررة.

هل تنتهي صلاحية أرصدة API؟

لا. تبقى الأرصدة المشتراة في حسابك حتى تستخدمها. يحصل كل حساب أيضًا على 10 تحويلات مجانية كل شهر، يتم استهلاكها قبل الأرصدة المدفوعة.

كيف يتم التعامل مع المدفوعات؟

تمر جميع المدفوعات عبر Lemon Squeezy بصفتها تاجر التسجيل: بطاقة، Apple Pay أو PayPal، ويتم حساب ضريبة القيمة المضافة/ضريبة المبيعات تلقائيًا، ويتم إرسال فاتورة عبر البريد الإلكتروني.

هل يمكنني الترقية لاحقًا؟

في أي وقت. لا تحتوي الإصدارات المجانية على حد زمني، ويمكن إضافة أرصدة Pro أو API عندما تنمو احتياجاتك — فجميعها تستخدم نفس محرك التحويل.
